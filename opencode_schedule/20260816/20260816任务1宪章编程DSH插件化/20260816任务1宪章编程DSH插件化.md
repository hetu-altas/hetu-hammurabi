## 一、任务要求

### 需求背景

宪章编程体系此前以「绝对路径 .ts 插件 + profile patch insert」形态挂接在 DSH web profile 上
（/cc 命令、硬门禁骨架、看板数据通道分散为多个手工配置条目），存在三个问题：
1. **非官方形态**：patch 用绝对路径引用源码文件，不符合 DSH 组合包（bundle）规范，无法 `dsh plugin` 安装/卸载
2. **硬门禁未挂载**：charter-gate 仅有 Python 判定核心，DSH 侧工具拦截钩子（`tools/pre-execute`）未接线，
   危险命令/通知出口/日志门禁在 DSH 下靠模型自觉
3. **看板需手动启动**：看板数据服务（8790）独立于 DSH 生命周期，需手动 `start_dashboard.sh`

### 目标

1. 整合为单一组合包 `plugins/constitution-coding/`（`@hetu-altas/ConstitutionCoding-Plugin`）：
   node 半区（/cc 命令、硬门禁、数据通道、看板自启）+ client 半区（看板面板、流程状态栏）
2. 硬门禁挂载 `tools/pre-execute`（危险命令/通知出口/日志门禁机器拦截）
3. 看板服务随 DSH 启动自动拉起（幂等）
4. 官方 `dsh plugin` 安装/卸载，profile 零手工配置

### 验收标准

1. `npx @deepseek-ai/dsh plugin --profile web add ./plugins/constitution-coding` 一条命令安装成功
2. 配置树含 5 行插件注册（constitution-coding/charter-command/charter-gate/charter-status-api/dashboard-launcher）
3. client 半区：boot manifest 注入 + `/plugins/<包名>/client.js` 200
4. 数据通道 `/api/hetu-dashboard/api/stats/overview` 返回真实数据；`/dashboard` 页面 200
5. **硬门禁**：危险命令无备份 → deny；curl 直连钉钉 → deny；未落闸写研发日志 → deny（单测 3 类覆盖）
6. **看板自启**：8790 停止状态下启动 dsh web，约 2 秒后自动拉起（health 200、dashboard.log 干净）
7. 单测：插件包 `plugin.test.mjs` 11/11；Python 全量回归通过
8. 文档：dsh-client-plugin.md 包边界章节、README/快速指南（中英）安装命令更新为 npx 写法

## 四、接口 / 数据格式定义

### 4.1 包 manifest（双面）

```jsonc
{
  "name": "@hetu-altas/ConstitutionCoding-Plugin",
  "main": "src/index.js",
  "exports": { ".": "./src/index.js", "./src/*": "./src/*", "./client": "./client.js", "./package.json": "./package.json" },
  "dsh": {
    "bundle": { "patch": "./cordis.patch.yml" },
    "client": { "inject": ["@deepseek-ai/dsh-client-runtime", "@deepseek-ai/dsh-client-ui-layout"], "platform": "web" }
  }
}
```

### 4.2 插件行（cordis.patch.yml）

| id | name | 说明 |
|----|------|------|
| constitution-coding | `包名` | node 入口（client 半区激活） |
| charter-command | `包名/src/command.js` | /cc 命令（**子路径必须带 .js 扩展名**：ESM 无自动补全） |
| charter-gate | `包名/src/gate.js` | tools/pre-execute 硬门禁 |
| charter-status-api | `包名/src/status-api.js` | 数据通道（inject: webServer） |
| dashboard-launcher | `包名/src/dashboard-launcher.js` | 看板自启 |

### 4.3 硬门禁判定（委托 Python 核心）

`tools/pre-execute` → 调 `python -m harness.core.cli decide --task-dir <最新任务目录> --run-id <目录名> --file --cmd --secret-file`
（**spawnSync 而非 execFileSync**：decide 拦截时退出码 1，execFileSync 抛异常会误放行）。
run_id 取 cwd 下最新任务目录（含 .gate.json 或状态文件）。
