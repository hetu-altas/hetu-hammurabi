# 河图 Logo 万相提示词 V2（第五期 · 极简中国风卷轴 / K 线 3 阳 2 阴 / 黑白红三色）

> 来源任务：20260804任务5 河图Logo万相提示词极简优化（任务目录 `opencode_schedule/20260804/20260804任务5河图Logo万相提示词极简优化/`）
> 产出日期：2026-08-09（charter-coder 编码节点产出）
> 用途：投喂**阿里通义万相（Wanx）模型**生成河图体系**极简中国水墨风** logo 底稿——V2 中文详细版主提示词可复制直投，参数与官方字段一一对应
> 传承关系：本文档为第四期万相提示词（任务4 `design/河图Logo万相提示词.md`，**只读保留**）的**极简化 V2 迭代**——用户实测万相出图反馈"生成的画卷过于写实、画面偏米黄暖调"，与"极简中国水墨风"定位不符，本版按用户三项指令重塑：①一定是极简中国风卷轴（去写实）；②K 线明确 3 阳 2 阴（可稍微夸张）；③就黑白红三色，不要米色
> 与第四期差异说明（V2 四大变更）：
> ① **去写实词清单对照**：删除 6 类写实质感词（宣纸纤维纹理清晰可见 / 墨分五色层次分明 / 圆柱卷曲的轴杆质感沉稳厚实 / 透着纸张的柔韧与自然 / 卷曲的边缘微微翘起 / 柔和均匀的纸面光感洒落画上）→ 强化极简词（极简、简练、疏朗、留白、线条洗练、平面、干净利落、疏朗空灵），光影类描述全部移除，保持平面感；
> ② **3 阳 2 阴固化**：V1 仅"阳线阴线疏密错落"未固定根数 → V2 明确"共 5 根 K 线、3 根阳线 2 根阴线"（阳线=朱砂红、阴线=墨黑，可夸张：影线长/实体粗/波动大/陡峭上扬）；
> ③ **8 色板 → 3 色板对照**（弃 8 色板原因见下，旧 8 色 hex 值一律不再使用、仅列旧色名）：淡赭纸、焦墨、重墨、淡墨、清墨、黛青、淡朱砂、哑金 → 纯白 `#FFFFFF`、墨黑 `#1C1C22`、朱砂红 `#B33A2E`（ratio 70/20/10）；
> ④ **长度区间收窄**：V1 [200,800] → V2 [200,700]（编码建议 300~600 字）。
> 弃 8 色板原因：用户实测万相出图反馈**"过于写实"+"画面偏米黄暖调"**——旧 8 色板含米色系（淡赭纸占底最大、清墨、哑金等），与"极简中国水墨风"定位不符；V2 按用户指令收敛为黑白红三色：纯白纸底（零米色风险）、墨黑主笔、朱砂红点睛。
> 使用前提：**不产出任何 SVG/XML 文件、不实际调用万相 API 出图**（无 Key/费用授权），实测生成由用户后续另行安排；本文档所有提示词与请求体均可直接复制投喂。

## 主提示词（万相中文详细版·极简优化）

> 用法：整段复制直投，填入 `input.prompt` 或 `messages.content.text`；负面句式内嵌于末尾、计入正文字数（V2 口径 [200,700] 字）。

**万相主提示词（中文详细版·极简优化，可直接投喂）：**

一幅横向展开的极简中国风画卷居中，半展开的横卷横陈于前，左右两端以纯黑细直杆轴杆立定，画幅四周留白不小于画布五分之一，疏朗透气、左右均衡。整幅作品为极简中国水墨风，线条洗练、笔触干净利落，画面保持平面感，通篇大量留白，疏朗空灵、素净高雅。卷面中央以毛笔手绘一幅水墨K线图，共5根K线，3根阳线为朱砂红色、2根阴线为墨黑色，影线修长、实体粗壮、上下影线长短错落、波动幅度大，走势陡峭上扬、笔触简洁利落。画面上方一根朱砂红色箭头蜿蜒折返、总体向上攀升，行至画幅上部渐渐加粗点睛，与墨色形成全图唯一的色彩对比。全图仅以纯白纸底、墨黑与朱砂红三色构成，通篇只保留黑白红三种颜色，简洁纯粹。画面右下角一方朱砂红方形印章落款，印文以抽象块面示意、不含真实文字。不要出现米色、米黄、淡赭、棕色、金色、渐变色、纹理、质感渲染、阴影、投影、三维立体、文字、水印。

## 万相参数配置

> 主推模型 `model=wan2.7-image-pro`（旗舰，支持 4K、`thinking_mode`、`color_palette`、`n` 参数，出图质量最佳）；备选模型 `wan2.6-t2i`（支持同步调用与 `negative_prompt`）。以下参数为基线建议值，数值随官方版本迭代，投喂前以官方最新文档为准。**V2 与第四期唯一参数差异：color_palette 由 8 色二期低饱和色板改为 3 色极简色板（黑白红），其余参数事实不变。**

### 推荐参数对照表（按模型分列）

| 参数 | wan2.7-image-pro（主推/旗舰） | wan2.6-t2i（备选） |
|------|------------------------------|--------------------|
| model | `wan2.7-image-pro`（主推旗舰，支持 4K） | `wan2.6-t2i`（备选，支持同步调用） |
| size | 16:9 横卷：`2688*1536`（或 4K `4096*2304`）；1:1 方图：`2048*2048`；自定义 768*768~4096*4096、宽高比 1:8~8:1 | 同左（按实际支持） |
| thinking_mode | `true`（默认，仅 wan2.7 系列） | 不支持 |
| prompt_extend | 不支持 → 显式 `false` 或不传 | 可 `true`（默认） |
| color_palette | **3 色极简色板（黑白红，见下）** | 不支持 |
| negative_prompt | 不支持（用正向"不要出现"句式） | 支持（可填负面清单） |
| n | 2（默认建议，出 2 张备选） | 1（同步） |

### size 三档建议

1. **16:9 横卷（主推）**：`2688*1536`（画卷横幅基因，与主提示词"横向展开画卷"构图一致；如需 4K 可用 `4096*2304`）；
2. **1:1 方图**：`2048*2048`（logo 通用构图，适合头像/图标场景，配合变体B）；
3. **自定义**：范围 `768*768` ~ `4096*4096`，宽高比 1:8 ~ 8:1；格式为**"宽*高"**（星号 `*` 分隔，非乘号 ×），如 `2688*1536` 即宽 2688、高 1536。

### thinking_mode 与 prompt_extend 说明

- `thinking_mode`：bool，默认 `true`，**仅 wan2.7 系列支持**（开启后模型先思考再出图，可提升画面质量与语义遵循度）；
- `prompt_extend`：bool，默认 `true`，**wan2.7 系列不支持该参数**——因本提示词已为详细长描述、无需智能改写扩写，故**显式传 `false` 或不传**即可（wan2.6-t2i 可传 `true` 使用默认智能扩写）。

### color_palette 3 色极简色板（仅 wan2.7 系列，3~10 色，ratio 总和须为 100%）

**V2 核心变更**：由第四期二期低饱和 8 色板（淡赭纸、焦墨、重墨、淡墨、清墨、黛青、淡朱砂、哑金）收敛为**黑白红 3 色极简色板**，ratio 遵循"白底最大 → 墨黑次之 → 朱砂红点睛"的极简用色逻辑：

| # | 色名 | hex | ratio | 用途逻辑 | 对照第四期 8 色板（仅旧色名） |
|---|------|-----|-------|----------|------------------------------|
| 1 | 纯白（纸底） | `#FFFFFF` | 70 | 画幅纸底占比最大（用户明示"不要米色"，纯白零米色风险） | 替代淡赭纸（原占底最大，弃） |
| 2 | 墨黑（主笔） | `#1C1C22` | 20 | 轴杆/阴线/主笔（非纯黑，保留墨色层次） | 替代焦墨+重墨+淡墨+清墨+黛青（弃） |
| 3 | 朱砂红（点睛） | `#B33A2E` | 10 | 阳线/箭头/印章点睛（经典朱砂，回归黑白红明快对比） | 替代淡朱砂+哑金（弃） |
| | **合计** | | **100** | 总和恒 100% | |

> 色值决策说明：纯白 `#FFFFFF`（用户"不要米色"，弃淡赭/米白系）；墨黑 `#1C1C22`（墨黑非纯黑，保留水墨层次）；朱砂红 `#B33A2E`（经典朱砂红，比第四期淡朱砂更纯粹，符合"黑白红"明确诉求）。ratio 遵循"白底最大 → 墨黑次之 → 朱砂红点睛"。

### API JSON 请求体示例（可直接投喂）

与官方字段一致，可直投（完整双入口示例见第五章投喂步骤，此处给 DashScope 原生风格单入口示例；`color_palette` 均为下方 3 色数组）：

```json
{
  "model": "wan2.7-image-pro",
  "input": {
    "prompt": "（此处粘贴 V2 万相主提示词全文）"
  },
  "parameters": {
    "size": "2688*1536",
    "thinking_mode": true,
    "prompt_extend": false,
    "color_palette": [
      { "color": "#FFFFFF", "ratio": 70 },
      { "color": "#1C1C22", "ratio": 20 },
      { "color": "#B33A2E", "ratio": 10 }
    ],
    "n": 2
  }
}
```

### n 生成数量

`n`：int，默认建议 **2**（一次生成 2 张备选，便于对比挑选；控制台批量可调）。

> 对照说明：第四期通用文档中其他模型（Midjourney、Stable Diffusion 等）的专属参数写法（宽高比与风格权重后缀、控制类参数等）均为其他模型口径，**通用口径，万相不适用**；万相投喂请严格使用上表与下方 JSON 字段。

## 负面要素处理

### 模型差异声明

**`wan2.7-image-pro` / `wan2.7-image` 不支持 negative_prompt 参数**（接口不识别该字段），不想要的内容必须写入**正向提示词**，以"不要出现……"句式陈述；仅备选模型 `wan2.6-t2i` **支持 negative_prompt**（若选备选可直接填负面清单）。

### wan2.7 替代写法（正向"不要出现"句式）

主提示词末尾已内嵌完整句式（不可删减，置于主提示词末尾、计入正文字数）：

> 不要出现米色、米黄、淡赭、棕色、金色、渐变色、纹理、质感渲染、阴影、投影、三维立体、文字、水印

### 负面要素清单（承接第四期禁词语义 + 实测反馈新增，转为正向句式）

| # | 负面禁词类别 | 万相正向句式化写法 |
|---|-------------|-------------------|
| 1 | 文字（text） | 不要出现任何文字 |
| 2 | 水印（watermark） | 不要出现水印 |
| 3 | 三维立体（3d render） | 不要出现三维立体渲染 |
| 4 | 写实照片（photorealistic） | 不要出现写实照片质感 |
| 5 | 杂乱堆砌（clutter） | 不要出现杂乱堆砌的元素 |
| 6 | 投影/阴影 | 不要出现投影、阴影 |
| 7 | 条形码/网格线/排版字样 | 不要出现条形码、网格线、排版字样 |
| 8 | 米色/米黄/淡赭（V2 新增，实测反馈驱动） | 不要出现米色、米黄、淡赭 |
| 9 | 棕色/金色（V2 新增，土黄/米色系） | 不要出现棕色、金色 |
| 10 | 渐变色（V2 新增） | 不要出现渐变色 |
| 11 | 纹理/质感渲染（V2 新增，写实质感类） | 不要出现纹理、质感渲染 |

> 建议：一次性把不需要的项并入主提示词末尾句式（见上"不要出现"完整句式，V2 已含全部 13 项禁词），可读性优先、不必逐项单独成句。

### wan2.6-t2i 直填 negative_prompt 示例（备选通道）

若选用备选模型 `wan2.6-t2i`，可直接填：

```json
"negative_prompt": "文字, 水印, 三维立体, 写实照片, 杂乱堆砌, 投影, 阴影, 条形码, 网格线, 排版字样, 米色, 米黄, 淡赭, 棕色, 金色, 渐变色, 纹理, 质感渲染"
```

> 字数口径注明："不要出现"句式**计入主提示词正文字数**（V2 长度口径 [200,700] 字含此段，8 组锚点断言不受影响）；句式置于主提示词末尾，"不要出现"之前的正文不出现任何米色系色名。

## 变体（3 个方向）

> 说明：每个变体给出方向名 + 一句**可替换 / 追加**的提示词片段（中文）+ 配套 size。追加片段直接补在"三色陈述"分句之后、"不要出现"句式之前即可；替换片段替换主提示词对应分句。**所有变体片段同样遵守极简三色约束**（无写实词、无米色系、无多色）。默认主提示词为基础版，3 个变体互不相同、非同图微调。

### 变体A｜16:9 横卷（主推）

- **要点**：完全展开横向极简画卷居中、左右两根纯黑细直杆轴杆立定、画幅全展开留白疏朗（承接任务1 方案1/方案3 双构图基因的极简化）。
- **追加片段**：一幅完全展开的横向极简画卷居中，左右两根纯黑细直杆轴杆立定，画幅全展开、留白疏朗、气势完整。
- **size 配套**：`2688*1536`（4K 可用 `4096*2304`）。

### 变体B｜1:1 方图极简紧凑

- **要点**：半展开横卷居中、四周留白加大至画布约三分之一、构图紧凑（logo 通用构图，适合方形头像与图标场景）。
- **追加片段**：卷轴在画面中占位约六成，四周留白加大至画布三分之一，构图紧凑居中、疏朗小巧。
- **size 配套**：`2048*2048`。

### 变体C｜朱砂印款（鼓励保留）

- **要点**：右下角朱砂红方印落款（抽象块面示意、不含真实文字，承接任务2 10 号母题）；**印章色=三色内的朱砂红 `#B33A2E`**，不引入任何其他颜色，不破坏黑白红三色约束。
- **追加片段**：卷轴右下角盖一枚朱砂红色方形印章落款，印文以抽象块面示意、不含真实文字，印章色属于三色内的朱砂红、不引入任何其他颜色。
- **size 配套**：随变体A（`2688*1536`/`4096*2304`）或变体B（`2048*2048`）搭配均可，推荐与变体B 组合出方形 logo 底稿。

## 投喂步骤

### 方式一：API 方式（两种入参入口）

**鉴权**：请求头携带 `Authorization: Bearer <DASHSCOPE_API_KEY>`（API Key 在阿里云百炼控制台"API-KEY 管理"获取，请妥善保管、勿外泄）。

**入口 1：DashScope 原生风格（`input.prompt`）**——POST 至 `https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis`：

```json
{
  "model": "wan2.7-image-pro",
  "input": {
    "prompt": "（此处粘贴 V2 万相主提示词全文）"
  },
  "parameters": {
    "size": "2688*1536",
    "thinking_mode": true,
    "prompt_extend": false,
    "color_palette": [
      { "color": "#FFFFFF", "ratio": 70 },
      { "color": "#1C1C22", "ratio": 20 },
      { "color": "#B33A2E", "ratio": 10 }
    ],
    "n": 2
  }
}
```

**入口 2：OpenAI 兼容风格（`messages.content.text`）**——POST 至 `https://dashscope.aliyuncs.com/compatible-mode/v1/images/generations`：

```json
{
  "model": "wan2.7-image-pro",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "（此处粘贴 V2 万相主提示词全文）"
        }
      ]
    }
  ],
  "parameters": {
    "size": "2688*1536",
    "thinking_mode": true,
    "prompt_extend": false,
    "color_palette": [
      { "color": "#FFFFFF", "ratio": 70 },
      { "color": "#1C1C22", "ratio": 20 },
      { "color": "#B33A2E", "ratio": 10 }
    ],
    "n": 2
  }
}
```

**调用后处理**：

1. 成功返回的图片 URL **24 小时内有效**，务必及时下载归档（建议按"任务日期+变体名"命名存盘）；
2. 若返回 `DataInspectionFailed`（内容安全审核未通过）：先自查提示词敏感措辞并删除，再降级重试（`n` 调为 1、`thinking_mode` 调 `false`），仍失败可换 `wan2.6-t2i` 备选模型（同步返回、支持 negative_prompt）；
3. 涉及素材版权合规：生成图仅作底稿，最终品牌定稿须走人工精修与矢量重绘流程。

### 方式二：百炼控制台方式

1. 打开阿里云百炼控制台（`bailian.console.aliyun.com`），进入**模型广场**或**文生图应用**；
2. 选择模型 **`wan2.7-image-pro`**（主推；如需 negative_prompt 可选 `wan2.6-t2i`）；
3. 将**V2 万相主提示词全文**粘贴到提示词输入框（中文直接粘贴即可，无需改写）；
4. 面板逐项填写参数：**尺寸**选 `2688*1536`（或按变体选 `2048*2048` 等，注意"宽*高"星号格式）、**思考模式**开（thinking_mode）、**色彩板**粘贴上方 **3 色 color_palette 数组**（纯白/墨黑/朱砂红，ratio 70/20/10；若面板支持直接录入色板）、**数量**选 2；
5. 点击生成，出图后**立即下载**（控制台生成图 URL 同样有时效，建议出图当天归档）。

**使用流程建议**：

1. **首轮**：按"V2 主提示词全文 + 参数配置（16:9 `2688*1536`、thinking_mode 开、3 色色板、n=2）"直投，出 2 张对比；
2. **微调**：从第四章 3 个变体选 1~2 个方向替换/追加片段，控制变量逐项验证（推荐先试变体A 横卷 + 变体C 印章款）；
3. **精选**：将效果最佳的 1~2 张底稿交由矢量重绘/人工精修，进入品牌资产定稿流程（与第一/二/三期 SVG 方案并案评估）。

**撰写规范要点（万相风格，供后续迭代参考）**：

1. **中文自然长描述**：万相对中文自然语言详细描述效果最佳；本提示词为 7 个分句连贯成文的自然长段落（构图→风格→K 线→箭头→三色→印章→负面句式），避免标签式堆砌；
2. **负面要素内嵌**：wan2.7 系列不支持 negative_prompt，不想要的内容一律以"不要出现……"句式写入正向提示词末尾（见第三章），该句式计入主提示词正文字数（V2 长度口径 [200,700] 字含此段，8 组锚点断言不受影响）；
3. **极简母题保留**：横向卷轴、纯黑细直杆轴杆、水墨 K 线（3 阳 2 阴）、朱砂红箭头点睛、留白 ≥ 1/5、三色陈述、右下角印章均在段落中逐句落实；写实质感词零出现（V2 核心）；
4. **禁止混入其他模型参数词**：主提示词正文只使用万相参数体系，不出现其他模型的参数符号表述（此类写法**通用口径，万相不适用**）。
