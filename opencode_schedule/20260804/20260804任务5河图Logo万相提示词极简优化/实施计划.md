### 3.2 V2 主提示词全文规划（逐句，编码目标 300~600 字）

主提示词为**万相风格中文自然长段落**（无【主体】分段，延续任务4 风格），7 个分句连贯成文。以下逐句给出措辞要点（编码节点可微调措辞，但**锚点词、禁词约束、三色陈述不得缺席**）：

| 句 | 内容要点 | 措辞草案（可润色） | 命中锚点/约束 |
|----|----------|--------------------|---------------|
| 句1 | 极简卷轴构图 | 一幅横向展开的极简中国风画卷居中，半展开的横卷横陈于前，左右两端以纯黑细直杆轴杆立定，画幅四周留白不小于画布五分之一，疏朗透气 | 锚点1 横向+画卷；去"圆柱卷曲轴杆质感" |
| 句2 | 极简风格陈述 | 整幅作品为极简中国水墨风，线条洗练、笔触干净利落，画面保持平面感，无质感渲染、无阴影渐变，通篇大量留白、疏朗空灵 | 锚点5 水墨、锚点6 极简；B1 平面/留白词 |
| 句3 | K 线 3 阳 2 阴（夸张） | 卷面中央以毛笔手绘一幅水墨K线图，共5根K线，3根阳线为朱砂红色、2根阴线为墨黑色，影线修长、实体粗壮、波动幅度大，走势陡峭上扬、笔触简洁利落 | 锚点2 K线、锚点7 3阳2阴；B2 夸张方向四要素 |
| 句4 | 红色箭头 | 画面上方一根朱砂红色箭头蜿蜒折返、总体向上攀升，行至画幅上部渐渐加粗点睛，与墨色形成全图唯一的色彩对比 | 锚点3 蜿蜒+向上攀升、锚点4 红色+箭头 |
| 句5 | 三色陈述 | 全图仅以纯白纸底、墨黑与朱砂红三色构成，通篇只保留黑白红三种颜色，简洁纯粹 | 锚点8 三色（纯白+墨黑+朱砂红） |
| 句6 | 印章点睛（三色内） | 画面右下角一方朱砂红方形印章落款，印文以抽象块面示意、不含真实文字 | 强化"朱砂"token；印章=三色内朱砂红 |
| 句7 | 负面句式（末尾，计字数） | 不要出现米色、米黄、淡赭、棕色、金色、渐变色、纹理、质感渲染、阴影、投影、三维立体、文字、水印 | A9 色名零残留取"不要出现"之前文本 |

**编码约束（逐句校验）**：
1. 句1~6（"不要出现"之前）**零出现**：`米|赭|金|棕` 相关色名、6 类写实词、`卷曲`（"卷轴/横卷"可保留，"卷曲"禁用）；
2. 句3 必须出现**数字式**"3根阳线""2根阴线"（锚点 7 正则口径：`(3|三)[根支]?阳(线)?` + `(2|两)[根支]?阴(线)?`），编码建议同时保证"共5根K线"总根数陈述；
3. 句5 必须同时出现 白色组（纯白/白色/白底）+ 黑色组（墨黑/黑色/纯黑/浓墨）+ 红色组（红色/朱砂红/朱砂）三组词（锚点 8）；
4. 全段不得混入其他模型参数词（`--ar`、`CFG`、`steps` 等）；
5. 去空白长度目标 **300~600 字**（上表草案合计约 340~360 字，留有余量；若不足 300 可适度扩充句1 构图与句3 夸张细节，若超 600 优先删冗余修饰、**锚点词不可删**）。

### 3.3 3 色 color_palette 配置（§4.3，A8/A9 核心）

| # | 色名 | hex | ratio | 用途逻辑 | 替代任务4 8 色板 |
|---|------|-----|-------|----------|------------------|
| 1 | 纯白（纸底） | `#FFFFFF` | 70 | 画幅纸底占比最大（用户"不要米色"，纯白零米色风险） | 替代淡赭纸（原 25，弃） |
| 2 | 墨黑（主笔） | `#1C1C22` | 20 | 轴杆/阴线/主笔（非纯黑，保留墨色层次） | 替代焦墨+重墨+淡墨+清墨+黛青（原 58，弃） |
| 3 | 朱砂红（点睛） | `#B33A2E` | 10 | 阳线/箭头/印章点睛（经典朱砂，黑白红明快对比） | 替代淡朱砂+哑金（原 17，弃） |
| | 合计 | | **100** | 总和恒 100% | |

**弃 8 色板原因（写入文档开篇说明区）**：用户实测万相出图反馈"过于写实"+"画面偏米黄暖调"——任务4 的 8 色板含米色系（淡赭纸 `#F3E9D6` 以 ratio 25 占底最大、清墨 `#B7AFA2`、哑金 `#A9976B` 等），与"极简中国水墨风"定位不符。V2 按用户指令收敛为黑白红三色：纯白纸底（零米色风险）、墨黑主笔、朱砂红点睛，ratio 遵循"白底最大 → 墨黑次之 → 朱砂红点睛"。

**API JSON 写法（可直接复制，唯一色板）**：
```json
"color_palette": [
  { "color": "#FFFFFF", "ratio": 70 },
  { "color": "#1C1C22", "ratio": 20 },
  { "color": "#B33A2E", "ratio": 10 }
]
```

> **关键陷阱**：V2 文档**任何位置**（含对照表、开篇说明、负面、翻车章节）**严禁出现任务4 旧 8 色 hex**（A9①全文档零残留断言）——对照说明只写旧色名（淡赭纸/焦墨/重墨/淡墨/清墨/黛青/淡朱砂/哑金），不写 hex 值。
