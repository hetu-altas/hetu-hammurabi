## 主提示词（万相中文详细版）

> 用法：整段复制直投，填入 `input.prompt` 或 `messages.content.text`；负面"不要出现"句式内嵌于末尾，计入正文字数。

**万相主提示词（中文详细版，可直接投喂）：**

一幅横向展开的水墨卷轴画卷居中悬于画面中央，半展开的横卷横陈于前，左右两端以焦墨轴杆立定，圆柱卷曲的轴杆质感沉稳厚实，宣纸卷面半卷半舒，卷曲的边缘微微翘起，透着纸张的柔韧与自然，横幅构图左右均衡，四周留白不小于画布五分之一，疏朗透气。整幅作品为极简中国水墨风，中式写意笔法从容洒脱，线条克制而内敛，宣纸米白淡赭纸底温润沉静，焦墨作主笔勾勒主体，全图用色极为克制。质感上宣纸纤维纹理清晰可见，墨色晕染自然渗化，墨分五色层次分明，飞白笔触苍劲有力，笔锋起收利落干脆，柔和均匀的纸面光感洒落画上，无投影、无立体渲染，保持纯粹的平面纸感。卷面中央以毛笔手绘一幅水墨K线图，蜡烛形态清晰可辨，阳线阴线疏密错落，笔触轻重与墨色浓淡随走势自然起伏，恰似行家即兴挥毫。画面上方一根朱砂红色箭头蜿蜒折返、总体向上攀升，行至画幅上部渐渐加粗点睛、提神收势，与墨色形成全图唯一的色彩对比。画面大量留白，极简高雅、疏朗空灵，意境悠远，适合作为品牌标识底稿。不要出现任何文字、水印、三维立体渲染、写实照片质感、杂乱堆砌的元素。

## 万相参数配置

> 主推模型 `model=wan2.7-image-pro`（旗舰，支持 4K `4096*4096`、`thinking_mode`、`color_palette`、`n` 参数，出图质量最佳）；备选模型 `wan2.6-t2i`（支持同步调用与 `negative_prompt`）。以下参数为基线建议值，数值随官方版本迭代，投喂前以官方最新文档为准。

### 推荐参数对照表（按模型分列）

| 参数 | wan2.7-image-pro（主推/旗舰） | wan2.6-t2i（备选） |
|------|------------------------------|--------------------|
| model | `wan2.7-image-pro`（主推旗舰，支持 4K） | `wan2.6-t2i`（备选，支持同步调用） |
| size | 16:9 横卷：`2688*1536`（或 4K `4096*2304`）；1:1 方图：`2048*2048`；自定义 768*768~4096*4096、宽高比 1:8~8:1 | 同左（按实际支持） |
| thinking_mode | `true`（默认，仅 wan2.7 系列） | 不支持 |
| prompt_extend | 不支持 → 显式 `false` 或不传 | 可 `true`（默认） |
| color_palette | 8 色二期低饱和色板（见下） | 不支持 |
| negative_prompt | 不支持（用正向"不要出现"句式） | 支持（可填负面清单） |
| n | 2（默认建议，出 2 张备选） | 1（同步） |

### size 三档建议

1. **16:9 横卷（主推）**：`2688*1536`（画卷横幅基因，与主提示词"横向横幅画卷"构图一致；如需 4K 可用 `4096*2304`）；
2. **1:1 方图**：`2048*2048`（logo 通用构图，适合头像/图标场景，配合变体B）；
3. **自定义**：范围 `768*768` ~ `4096*4096`，宽高比 1:8 ~ 8:1；格式为**"宽*高"**（星号 `*` 分隔，非乘号 ×），如 `2688*1536` 即宽 2688、高 1536。

### thinking_mode 与 prompt_extend 说明

- `thinking_mode`：bool，默认 `true`，**仅 wan2.7 系列支持**（开启后模型先思考再出图，可提升画面质量与语义遵循度）；
- `prompt_extend`：bool，默认 `true`，**wan2.7 系列不支持该参数**——因本提示词已为详细长描述、无需智能改写扩写，故**显式传 `false` 或不传**即可（wan2.6-t2i 可传 `true` 使用默认智能扩写）。

### color_palette 色板（仅 wan2.7 系列，3~10 色，ratio 总和须为 100%）

二期低饱和 8 色板直用（来源：`docs/brand/河图体系Logo设计.md` 第六节），ratio 遵循"淡赭纸底最大 → 焦墨主笔次之 → 淡朱砂点睛"的河图用色逻辑：

| # | 色名 | hex | ratio | 用途逻辑 |
|---|------|-----|-------|----------|
| 1 | 淡赭纸 | `#F3E9D6` | 25 | 纸底占比最大（宣纸底） |
| 2 | 焦墨 | `#3B3733` | 20 | 主笔次之（轴杆/最重笔触） |
| 3 | 重墨 | `#57504A` | 12 | 阴线/中层晕染 |
| 4 | 淡墨 | `#8D8578` | 10 | 影线/刻度/晕染中层 |
| 5 | 清墨 | `#B7AFA2` | 8 | 云雾/纸纹/飞白 |
| 6 | 黛青 | `#4E5D66` | 8 | 远山青黛/阴线点缀 |
| 7 | 淡朱砂 | `#A96B5F` | 10 | 点睛（箭头/印章） |
| 8 | 哑金 | `#A9976B` | 7 | 轴头/高光线 |
| | **合计** | | **100** | 总和恒 100% |

API JSON 中 `color_palette` 数组写法（可直接复制）：

```json
"color_palette": [
  { "color": "#F3E9D6", "ratio": 25 },
  { "color": "#3B3733", "ratio": 20 },
  { "color": "#57504A", "ratio": 12 },
  { "color": "#8D8578", "ratio": 10 },
  { "color": "#B7AFA2", "ratio": 8 },
  { "color": "#4E5D66", "ratio": 8 },
  { "color": "#A96B5F", "ratio": 10 },
  { "color": "#A9976B", "ratio": 7 }
]
```

### n 生成数量

`n`：int，默认建议 **2**（一次生成 2 张备选，便于对比挑选；控制台批量可调）。

> 对照说明：任务3 通用文档中 Midjourney、Stable Diffusion 等模型的专属参数写法（宽高比与风格权重后缀、CFG 类控制参数等）均为其他模型口径，**通用口径，万相不适用**；万相投喂请严格使用上表与下方 JSON 字段。

## 负面要素处理

### 模型差异声明

**`wan2.7-image-pro` / `wan2.7-image` 不支持 negative_prompt 参数**（接口不识别该字段），不想要的内容必须写入**正向提示词**，以"不要出现……"句式陈述；仅备选模型 `wan2.6-t2i` **支持 negative_prompt**（若选备选可直接填负面清单）。

### wan2.7 替代写法（正向"不要出现"句式）

主提示词末尾已内嵌完整句式（不可删减）：

> 不要出现任何文字、水印、三维立体渲染、写实照片质感、杂乱堆砌的元素

### 负面要素清单（承接任务3 禁词语义，转为正向句式）

| # | 任务3 负面禁词 | 万相正向句式化写法 |
|---|---------------|-------------------|
| 1 | 文字（text） | 不要出现任何文字 |
| 2 | 水印（watermark） | 不要出现水印 |
| 3 | 三维渲染（3d render） | 不要出现三维立体渲染 |
| 4 | 写实照片（photorealistic） | 不要出现写实照片质感 |
| 5 | 杂乱堆砌（clutter） | 不要出现杂乱堆砌的元素 |
| 6 | Logo/边框/签名/画框/图标 | 不要出现额外Logo、边框、签名、画框、图标 |
| 7 | 阴影/渐变 | 不要出现投影、渐变 |
| 8 | 条形码/网格线/排版字样 | 不要出现条形码、网格线、排版字样 |

> 建议：一次性把不需要的项并入主提示词末尾句式（如"不要出现任何文字、水印、三维立体渲染、写实照片质感、杂乱堆砌的元素、投影、渐变、条形码、网格线"），可读性优先、不必逐项单独成句。

### wan2.6-t2i 直填 negative_prompt 示例（备选通道）

若选用备选模型 `wan2.6-t2i`，可直接填：

```json
"negative_prompt": "文字, 水印, 三维渲染, 写实照片, 杂乱堆砌, logo, 边框, 签名, 画框, 图标, 阴影, 渐变, 条形码, 网格线, 排版字样"
```

> 字数口径注明："不要出现"句式**计入主提示词正文字数**（200~800 字口径含此段），6 组锚点断言不受影响。

## 变体（3 个方向）

> 说明：每个变体给出方向名 + 一句**可替换 / 追加**的提示词片段（中文）+ 配套 size。追加片段直接补在"留白质量"分句之后、"不要出现"句式之前即可；替换片段替换主提示词对应分句。默认主提示词为基础版，3 个变体互不相同、非同图微调。

### 变体A｜16:9 横卷全景（主推）

- **要点**：完全展开横幅画卷、左右卷曲焦墨轴杆、全谱系展开气势（承接任务1 方案1/方案3 双构图基因）。
- **追加片段**：一幅完全展开的横向水墨横幅画卷居中，左右两根焦墨卷曲轴杆立定，画卷两端可见卷曲的纸背边缘，全谱系展开、气势完整。
- **size 配套**：`2688*1536`（4K 可用 `4096*2304`）。

### 变体B｜1:1 方图居中紧凑

- **要点**：半展开横卷居中、四周留白加大至画布 1/3、画面紧凑，适合方形头像与图标场景。
- **追加片段**：卷轴在画面中占位约六成，四周留白加大至画布三分之一，构图紧凑居中，疏朗小巧、气韵绵长。
- **size 配套**：`2048*2048`。

### 变体C｜印章款（鼓励第三变体）

- **要点**：右下角淡朱砂方印落款（抽象块面示意、不含真实文字），仿任务2 10 号"落款为凭"母题，作品感更足。
- **追加片段**：卷轴右下角盖一枚淡朱砂色方形印章落款，印文以抽象块面示意、不含真实文字。
- **size 配套**：随变体A（`2688*1536`/`4096*2304`）或变体B（`2048*2048`）搭配均可，推荐与变体B 组合出方形 logo 底稿。

## 投喂步骤

### 方式一：API 方式（两种入参入口）

**鉴权**：请求头携带 `Authorization: Bearer <DASHSCOPE_API_KEY>`（API Key 在阿里云百炼控制台"API-KEY 管理"获取，请妥善保管、勿外泄）。

**入口 1：DashScope 原生风格（`input.prompt`）**——POST 至 `https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis`：

```json
{
  "model": "wan2.7-image-pro",
  "input": {
    "prompt": "（此处粘贴万相主提示词全文）"
  },
  "parameters": {
    "size": "2688*1536",
    "thinking_mode": true,
    "prompt_extend": false,
    "color_palette": [
      { "color": "#F3E9D6", "ratio": 25 },
      { "color": "#3B3733", "ratio": 20 },
      { "color": "#57504A", "ratio": 12 },
      { "color": "#8D8578", "ratio": 10 },
      { "color": "#B7AFA2", "ratio": 8 },
      { "color": "#4E5D66", "ratio": 8 },
      { "color": "#A96B5F", "ratio": 10 },
      { "color": "#A9976B", "ratio": 7 }
    ],
    "n": 2
  }
}
```

**入口 2：OpenAI 兼容风格（`messages.content.text`）**——POST 至 `https://dashscope.aliyuncs.com/compatible-mode/v1/images/generations`：

```json
{
  "model": "wan2.7-image-pro",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "（此处粘贴万相主提示词全文）"
        }
      ]
    }
  ],
  "parameters": {
    "size": "2688*1536",
    "thinking_mode": true,
    "prompt_extend": false,
    "color_palette": [
      { "color": "#F3E9D6", "ratio": 25 },
      { "color": "#3B3733", "ratio": 20 },
      { "color": "#57504A", "ratio": 12 },
      { "color": "#8D8578", "ratio": 10 },
      { "color": "#B7AFA2", "ratio": 8 },
      { "color": "#4E5D66", "ratio": 8 },
      { "color": "#A96B5F", "ratio": 10 },
      { "color": "#A9976B", "ratio": 7 }
    ],
    "n": 2
  }
}
```

**调用后处理**：

1. 成功返回的图片 URL **24 小时内有效**，务必及时下载归档（建议按"任务日期+变体名"命名存盘）；
2. 若返回 `DataInspectionFailed`（内容安全审核未通过）：先自查提示词敏感措辞并删除，再降级重试（`n` 调为 1、`thinking_mode` 调 `false`），仍失败可换 `wan2.6-t2i` 备选模型（同步返回、支持 negative_prompt）；
3. 涉及素材版权合规：生成图仅作底稿，最终品牌定稿须走人工精修与矢量重绘流程。

### 方式二：百炼控制台方式

1. 打开阿里云百炼控制台（`bailian.console.aliyun.com`），进入**模型广场**或**文生图应用**；
2. 选择模型 **`wan2.7-image-pro`**（主推；如需 negative_prompt 可选 `wan2.6-t2i`）；
3. 将**万相主提示词全文**粘贴到提示词输入框（中文直接粘贴即可，无需改写）；
4. 面板逐项填写参数：**尺寸**选 `2688*1536`（或按变体选 `2048*2048` 等，注意"宽*高"星号格式）、**思考模式**开（thinking_mode）、**色彩板**粘贴上方 8 色 color_palette 数组（若面板支持直接录入色板）、**数量**选 2；
5. 点击生成，出图后**立即下载**（控制台生成图 URL 同样有时效，建议出图当天归档）。

## 翻车规避（使用说明）

> 万相特有规避清单（每类：现象 → 万相侧规避手段）；任务3 通用文档中其他模型（Midjourney、Stable Diffusion 等）的规避参数写法为**通用口径，万相不适用**，以本表为准。

| # | 现象 | 万相侧规避手段 |
|---|------|---------------|
| 1 | **K 线被读成条形码/几何条**：蜡烛变成整齐等宽条 | 主提示词强调"毛笔手绘水墨K线、蜡烛形态清晰可辨、阳线阴线疏密错落、笔触轻重与墨色浓淡随走势自然起伏"——用笔触浓淡变化打破几何均质感（已在主词中落实，勿删减该分句） |
| 2 | **文字乱码/伪汉字**：画面出现乱码字符或伪汉字 | wan2.7 无 negative_prompt 时的唯一通道即正向句"不要出现任何文字"，并避免在描述中使用字形类词汇；主词末尾句式已含，勿删减 |
| 3 | **风格不统一**：水墨与写实混搭、半卷半照片 | 将"极简中国水墨风"作为风格限定**前置**于描述开头加重权重，并保留"中式写意笔法、线条克制"同义叠加；末尾"不要出现写实照片质感"兜底 |
| 4 | **红色箭头过细被吞**：箭头在留白中看不清 | 主词已强调"朱砂红色箭头蜿蜒折返、总体向上攀升、行至画幅上部渐渐加粗点睛"，必要时单独成句再次强调"画幅上部加粗点睛"，或改用变体C 以印章呼应强化视觉落点 |
| 5 | **数据审核失败（DataInspectionFailed）** | 自查提示词敏感词（避免血腥/危险场景类表述）→ 降级重试：`n` 调 1、`thinking_mode` 调 `false` → 仍失败换 `wan2.6-t2i` 备选 |
| 6 | **元素拼贴/割裂**：卷轴、K 线、箭头各自为政 | 元素种类克制在 5 类以内（卷轴、轴杆、K 线、箭头、印章），保留"单主体居中、左右均衡"构图词；追加片段控制在每变体 1 句 |
| 7 | **URL 过期**：生成的图片链接失效 | 出图后 **24 小时内**下载归档（本任务不产图，归档由用户管理） |

**使用流程建议**：

1. **首轮**：按"主提示词全文 + 参数配置（16:9 `2688*1536`、thinking_mode 开、8 色色板、n=2）"直投，出 2 张对比；
2. **微调**：从第四章 3 个变体选 1~2 个方向替换/追加片段，控制变量逐项验证（推荐先试变体A 横卷全景 + 变体C 印章款）；
3. **精选**：将效果最佳的 1~2 张底稿交由矢量重绘/人工精修，进入品牌资产定稿流程（与第一/二/三期 SVG 方案并案评估）。

**撰写规范要点（万相风格，供后续迭代参考）**：
