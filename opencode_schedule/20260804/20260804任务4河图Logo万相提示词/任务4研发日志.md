## 一、任务概述

本任务为河图品牌设计资产类任务**第四期（万相专属提示词特化）**：前两期（任务1 极简系列、任务2 水墨强化系列）为 SVG 矢量方案，第三期（任务3）产出多模型通用提示词工程文档（`design/河图Logo文生图提示词.md`，8 段中文主提示词 347 字、6 组锚点正则、5 变体），均已评审通过。用户已选定**阿里通义万相（Wanx）模型**作为主力出图模型，而任务3 通用文档中"通义万相"一行的参数写法已不足以支撑直接投喂（如 wan2.7 系列不支持 negative_prompt、需 color_palette 参数、size 格式为"宽*高"等），故本任务在任务3 通用提示词基础上，针对万相模型特性产出**万相专属提示词文档（中文详细版为主，可复制直投）**。

- **调研来源**：万相 API 事实由编排者从官方文档核实（阿里云百炼《千问qwen-image和万相wan模型文生图使用方式》：`help.aliyun.com/zh/model-studio/text-to-image`），核实结论写入任务书 §4.1 事实基线（wan2.7-image-pro 旗舰能力、wan2.7 系列不支持 negative_prompt 与 prompt_extend、color_palette 8 色、size 宽*高格式等），本任务文档引用事实一律以任务书为权威基线，禁止虚构参数；
- **任务性质**：品牌设计资产类任务（非业务代码库任务），**纯文档产出**——无 SVG/XML 产出、无数据库/网络调用、不实际调用万相 API 出图（无 API Key 与费用授权，实测出图由用户后续自行安排）；
- **交付目标**：`design/河图Logo万相提示词.md`（6 章节、275 行）+ 文档文本断言单测 15 用例（复用任务3 锚点口径 + 新增万相参数断言），通过 A/B/C 三类验收后归档于任务目录；
- **流程节点**：节点 -1 任务书生成（269 行）→ 节点 1 分析（实施计划）→ 节点 2 编码（万相提示词文档）→ 节点 3 单元测试（**15/15 全部通过**）→ 节点 4 评审（**一次 REVIEW:APPROVE**）→ **节点 5 研发日志（本文）**；

### 5.6 投喂步骤（A11 断言对象，双通道）
