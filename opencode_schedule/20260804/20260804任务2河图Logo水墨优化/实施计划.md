## 一、任务概述与验收标准

### 1.1 任务概述

以任务1 评审通过的 02 号方案（`hetu_logo_02.svg`，立轴挂轴：绦带 + 天/地杆 + 竖向画幅 + 7 根 K 线 + 周期刻度）为架构基准，**一次性产出 5 版"中式水墨强化"候选** `hetu_logo_06.svg` ~ `hetu_logo_10.svg`，全部为纯矢量、自包含、可直接使用的独立 SVG；附第二期设计说明（`design/设计说明.md`），与任务1 的 01~05 并案比较，支撑"水墨系列"vs"极简系列"决策。

核心优化点（对应任务1 评审遗留问题与二期约束）：
1. **水墨元素更浓**：五色墨阶（焦/重/淡/清 + opacity 分层模拟浓淡）+ 晕染 + 留白 + 笔触，至少呈现其三（B1）；
2. **K 线中式手绘**：影线分段 stroke（起笔重、收笔轻）+ 实体笔刷 path 填充，禁止纯 `rect`+`line` 直边拼装（A9/B2）；
3. **滚筒加大**：天/地杆轴向厚度 T 占画幅宽 W 之比 ∈ [0.08, 0.14]（02 仅 6.7%），带圆柱立体感（渐变/高光线）与轴头装饰（B3/A8）；
4. **低饱和色板**：二期固化 8 色（§4.1 任务书）全组强制一致，每文件去重颜色 token ≤ 8（A6/A7）；
5. **命名与传承**：命名 `hetu_logo_06~10.svg`（禁覆盖任务1 文件），5 版基于 02 立轴架构差异化演绎（母题/笔触/装饰/构图不同，差异必须明显）。

### 3.1 二期低饱和色板精确用法与色 token 预算表

**纪律（对应 A6/A7）**：
- A6 计数口径：仅 `fill`/`stroke` 属性（含 `style` 内联）中的 `#`/`rgb()`/`url(#grad-x)` 去重 ≤ 8；`url(#grad-x)` 计 1 种；`stop-color` **不**计入 A6 计数（沿用任务1 口径）；
- A7 校验口径：`fill`/`stroke` 全部颜色 **与** 所有 `stop-color` 必须 ∈ 8 色板（`_collect_palette_tokens` 覆盖）；`opacity` 不计 token，是"五色墨阶"主要模拟手段（焦墨 1.0/0.7/0.4/0.15 等）；
- 每文件渐变 ≤ 2 个，`id` 前缀统一 `grad-`，全部内联；本组统一为每文件 **1 个或 0 个渐变**（见预算表）。
