## 三、五版候选意图与适用场景

### 候选 6｜`hetu_logo_06.svg` —— 五色墨阶纯墨系（笔锋最重）

**构图摘要**：画幅内四层同心墨晕（清 0.08 → 淡 0.10 → 重 0.07 → 焦 0.05）如墨入水纸，K 线以全组最重笔锋书写（3 段影线 2.6→0.8、实体笔刷 10/6 + 渗化尾层 0.5），滚筒 T=22（12.2%，`grad-roll` 焦→重→淡三 stop 圆柱渐变）+ 哑金轴头 + 双垂穗。

**意涵**：墨分五色即浓淡相宜——"规律在浓淡深浅中被层层读解"；笔锋如书法运笔，量化数据以笔墨入卷。

**适用场景**：品牌主标识候选（竖版）、书法气质浓的正式场合、体系发布会主视觉竖幅；**与 08（笔触最柔）成两极，供评审对比"重笔"与"柔笔"路线**。

### 候选 7｜`hetu_logo_07.svg` —— 远山黛青（山水入画）

**构图摘要**：画幅下部三层山形层叠（清墨 0.55 最远 → 淡墨 0.7 → 黛青 0.85 最近最实），K 线自山前升起，实体直笔稍直呼应山势（弯度 ≤2°）；滚筒 T=18（10.0%，重→淡双 stop 木色渐变）+ 重墨轴头（全组唯一无金）+ 单垂穗。

**意涵**：山水即市场——K 线如山脉起伏，涨跌如峦，量化投研"观山知势"；青黛点缀全组最明显，是"水墨"与"色彩"结合的平衡点。

**适用场景**：需要传达"中式美学 + 数据分析"双气质的场合（官网首屏、行业报告封面）；山水意象受众接受度最高。

### 候选 8｜`hetu_logo_08.svg` —— 水纹涟漪（水月镜花，笔触最柔）

**构图摘要**：画幅下部三道波浪（清墨 1.5/1.2、淡墨 1.0，opacity 0.6→0.4）如涟漪，kl-5/6/7 实体底部淡墨渗墨点（r=6.5~7.5，opacity 0.4）如烛影入水；K 线影线仅 2 段（1.8→0.6）全组最细最柔；滚筒 T=16（8.9%，本组最小仍达标）+ 木色双色渐变 + 重墨轴头 + 双分叉垂穗（本组最宽）。

**意涵**：K 线如水中烛影——"数据波动如水面涟漪，规律在水月镜花中澄明"；全组上部留白最大（y 118~230 全空），与 06 的"重"形成两极。

**适用场景**：产品形象偏"轻盈、流动"的子项目（如 hetu-mercury 数据接口层延展）、白皮书封面、需要安静气质的场合。

### 候选 9｜`hetu_logo_09.svg` —— 云雾留白（渐隐于雾，禅意最浓）

**构图摘要**：画幅上部三团清墨云纹（0.15/0.25/0.35，椭圆+弧线复合，无实边），kl-6/kl-7 影线顶（y=202）隐入云中——实体加清墨雾化层（opacity 0.4）并降为 0.55、影线降为 0.6，"上段 K 线渐隐于雾"，kl-7 顶部飞白收笔；滚筒 T=20（11.1%，焦→重→淡三 stop）+ 哑金双轴头 + 挂环加大 r=6（本组最大）；刻度全组最淡（0.25/0.35）。

**意涵**：云雾是"留白的气韵"——规律未被完全揭示的部分如雾中隐现，K 线自雾中渐显又渐隐，对应"规律在未知中显现"的投研哲学；禅意与留白最强。

**适用场景**：品牌升级/理念传达类场景、文化展陈、需要"克制高级感"的场合；与 07 同属山水系但情绪相反（07 实、09 虚）。

### 候选 10｜`hetu_logo_10.svg` —— 印章落款 + 纸纹（卷面"作品感"最足）

**构图摘要**：画幅右下角淡朱砂方印 36×36（rx=4，2 块白文留白 + 竖分隔线，无真实文字规避字体依赖），置顶压刻度线仿"印压线"传统；左右缘各一条清墨折痕线（微弯、opacity 0.3）拟宣纸纤维；K 线实体微斜 2.5°（tan 精确代入，顶/底偏移 ±1.3~1.7px 按实体高）显手写感，kl-7 阳线末端两级飞白勾（1.0→0.5）；滚筒 T=24（13.3%，本组最大）+ 焦墨主体 + 哑金高光线（无渐变，8 token 恰满）+ 双端哑金轴头 + 最粗挂绳 3.5 + 双垂穗。

**意涵**：印章是"落款为凭"——数据图谱如作品落印定稿，纸纹折痕还原卷面质感；最大筒径 + 高光线是"作品装裱"的完成态表达。

**适用场景**：正式定稿场景（年报封面、合作签约视觉、体系庆典主视觉）；"作品感"最强，适合作"最终选定"路线的压轴候选。

## 五、与任务1（01~05 极简系列）并案对比建议

| 对比项 | 第一期 01~05（极简系列） | 第二期 06~10（水墨系列） |
|--------|--------------------------|--------------------------|
| 气质 | 中式极简 + 科技感（点阵/网格/渐变描边） | 中式水墨 + 手写感（墨阶/晕染/笔触/留白） |
| 色感 | 高饱和 6 色（朱砂/鎏金/玄青明快） | 低饱和 8 色（暖黑灰/黛青/淡朱砂/哑金沉静） |
| K 线 | 几何 rect+line 精确排布 | 毛笔 path 手绘（起笔重收笔轻） |
| 滚筒 | 12px 细杆（6.7%） | 16~24px（8.9%~13.3%）+ 圆柱渐变/轴头 |
| 母题 | 点阵/曲线/折线/网格（量化直译） | 墨晕/远山/水纹/云雾/印章（意象转译） |
| 同架构 | 02 与 06~10 共享立轴挂轴骨架，是并案比较的天然锚点 | 同左 |

**并案建议**：
1. **若定位"量化基础设施"优先**：推荐 02（几何立轴）或 06（水墨最重但 K 线语义最清晰）——业务属性最直白；
2. **若定位"中式品牌美学"优先**：推荐 07（山水意象 + 色彩平衡）或 10（作品感 + 最大筒径）——记忆点最强；
3. **若需中间路线**：08/09 分别代表"柔"与"虚"，适合子品牌延展（如 hetu-mercury 用 08 水纹、hetu-thoth 用 09 云雾），与主标识构成家族；
4. **落地注意**：水墨系列依赖低透明度叠色，缩小至图标尺寸（<64px）时 06 晕染与 09 云雾层次会衰减，建议正式选用时按 500 画布原比例缩放且不低于 96px 展示；深色底需另出反白版。

## 六、编码节点偏差说明（评审可核）

1. **绦带绘制层级**：挂环/挂绳/垂穗统一置于全文件最上层（`scroll-ribbon` 分组位于末尾），确保加大滚筒（天杆上缘 96~102）不遮挡挂环、垂穗 134~162 完整可见——02 中穗 112~138 曾被画幅遮住 20px，本组修正；
2. **10 号印章置顶**：印章独立分组置于刻度组之后，仿"印压线"传统盖住 tick-7 与基线交汇段（印章 x=300~336 与刻度 x=316 有 16px 交汇），避免刻度线穿印面；
3. **10 号天杆顶 y=94**：为达成 13.3% 最大筒径，顶部留白 94px，低于 95px 参考线 1px——A 类无留白断言，B 类请评审按"最大筒径优先"裁定；
4. **06 晕染为四层**（清/淡/重/焦，0.05~0.10）：实施计划列三层（焦/重/淡），为落实色 token 预算表中清墨角色（`#B7AFA2` 全组必用）并强化"墨分五色"叙事，外层增加清墨最淡层，视觉仅 4% 增色，不改变"纯墨晕染"母题；
5. **给节点3 的口径提示**（重要）：`_svg_files` 的 glob 模式 `hetu_logo_0*.svg` 无法匹配 `hetu_logo_10.svg`（文件名第 11 字符为 "1" 非 "0"），请改用 `hetu_logo_*.svg` 或同时匹配两个模式，否则用例 1 数量断言（期望 5 个）将失败；`_collect_palette_tokens` 校验时请剔除 `url(#...)` 引用 token（渐变引用非颜色，其颜色安全由 `stop-color` 校验承担），仅对实际颜色值（hex/rgb）与 `stop-color` 断言 ⊆ 二期 8 色板，否则 06~09（含 `fill="url(#grad-roll)"`）将被误判为色板外。
