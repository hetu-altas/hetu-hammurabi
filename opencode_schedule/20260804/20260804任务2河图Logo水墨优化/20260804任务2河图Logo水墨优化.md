## 一、任务要求

- **需求背景**：任务1 已产出 5 个备选 Logo（`hetu_logo_01~05.svg`）并通过评审，其中 02 号方案（立轴挂轴式：天/地杆 + 绦带垂穗 + 竖向画幅内嵌 7 根 K 线 + 周期刻度）构图与业务叙事俱佳，但存在优化空间：水墨韵味不足、K 线几何感偏强、滚筒偏细、颜色饱和度过高。本轮以 02 为基准，按 dev 流程继续优化，产出 5 版"中式水墨强化"候选，供决策层与 01~05 并案比较。
- **目标**：以 `hetu_logo_02.svg`（立轴挂轴 + K 线）为架构基准，**一次性生成 5 个水墨优化候选**（`hetu_logo_06.svg` ~ `hetu_logo_10.svg`，纯矢量、自包含、可直接使用），并附第二期设计说明，支撑"水墨系列"与"极简系列"（任务1）并案决策。
- **需求要点（4 项设计约束 + 1 项命名约束，缺一不可）**：
  1. **中式水墨元素更浓**：墨色浓淡层次（焦/浓/重/淡/清五色墨阶，受 8 色限制可用"色板墨色 + opacity 分层"模拟）、留白与晕染、笔触感（stroke 宽度变化、透明度分层模拟笔锋）、可引入**远山 / 水纹 / 云雾**等水墨母题点缀；
  2. **K 线中式手绘（毛笔笔触）**：K 线本体保持可辨识的蜡烛形态（阳线/阴线、影线、实体），但线条带手绘感——起笔重、收笔轻、边缘不齐，避免几何直边；实现建议见四 §4.2；
  3. **卷轴滚筒更大**：天/地杆（滚筒）轴向厚度显著增大（**占画幅宽 8%~14%**，口径见四 §4.3），具圆柱立体感（渐变/高光线），可加轴头装饰（哑金/木色轴头）；绦带保留或加粗；
  4. **中式低饱和度色板**：底色用宣纸米白/淡赭纸色，墨色用低饱和暖黑灰（非纯黑 `#000`），点缀用淡赭/黛青/淡朱砂/哑金（饱和度显著低于任务1 色板）；**精确 hex 在本任务书四 §4.1 固化，全组强制一致**；
  5. **命名与传承**：产出 5 版，命名 `hetu_logo_06.svg` ~ `hetu_logo_10.svg`（与任务1 的 01~05 区分，**禁止覆盖任务1 文件**）；5 版须基于 02 的立轴挂轴架构做差异化演绎（K 线笔触浓淡差异、水墨母题不同、滚筒装饰不同、构图微调），但**差异必须明显**（非同图微调）。
- **验收标准**（沿用任务1 的 A/B/C 三类框架，全部满足才算通过）：

  **A. 交付物验收（可被单元测试断言，硬门禁）**：
  1. `design/` 目录下**恰好 5 个** SVG 文件，命名 `hetu_logo_06.svg` ~ `hetu_logo_10.svg`，另含 1 份 `design/设计说明.md`；
  2. 每个 SVG 为合法 XML（`xml.etree.ElementTree` 可解析），根元素为 `<svg>`，标签闭合配对；
  3. 每个 SVG 的 `viewBox` 为 `0 0 500 500` 或 `0 0 1024 1024`（宽高相等），且 `width`/`height` 声明与 viewBox 比例一致（可为具体像素或省略/100%）；
  4. **自包含**：无 `<image>` 位图引用、无 `url(...)` 外链、无 `<link>`/`@import` 外部样式表引用；文本若使用 `font-family`，仅限通用安全字体族；
  5. **卷轴意象可断言**：每个 SVG 中卷轴元素统一放在以 `id="scroll-"` 开头的分组 `<g>` 内（`scroll-roll` 滚筒 / `scroll-body` 画幅 / `scroll-ribbon` 绦带）；
  6. **颜色受控**：每个 SVG 中 `fill`/`stroke` 属性引用的去重颜色数量（含 `#RRGGBB`、`#RGB`、`rgb()`、`url(#渐变)`）**≤ 8 种**；
  7. **低饱和色板约束（二期新增，可断言）**：每个 SVG 的 `fill`/`stroke` 引用的所有颜色（含渐变 `stop-color`）**必须全部属于二期固化色板（四 §4.1 的 8 色）**，禁止出现任务1 高饱和色板色（`#B33A2E`、`#C0A062`、`#264653`、`#1C1C22` 等）与任何色板外颜色；
  8. **滚筒尺寸约束（二期新增，可断言）**：每个 SVG 天/地杆（`scroll-roll` 分组内滚筒主体元素）的**轴向厚度**与**画幅宽**（`scroll-body` 分组内主画幅矩形宽度）之比 **∈ [0.08, 0.14]**（计算口径见四 §4.3）；
  9. **K 线手绘结构约束（二期新增，可断言）**：每个 SVG 的 K 线量化分组（`id` 含 `kline` 或 `quant-` 前缀分组）内**至少存在 1 个 `<path>` 元素**（手绘笔触载体），K 线不得全部由纯几何 `<rect>`+`<line>` 构成。

  **B. 设计质量验收（节点4 评审人工判定，软门禁）**：
  1. **水墨感浓**：五色墨阶/晕染/留白/笔触感至少呈现其三，一眼为"水墨画"而非"扁平插画"；
  2. **K 线手绘可辨**：起笔重、收笔轻、边缘不齐的毛笔感明显，同时蜡烛形态（影线 + 实体、阳/阴）仍可辨识，未失去 K 线语义；
  3. **滚筒显著加大**：天/地杆视觉占比显著（≥8% 画幅宽），圆柱立体感（渐变/高光）与轴头装饰可见；
  4. **低饱和中式色**：整体为淡赭纸 + 暖墨灰 + 黛青/淡朱砂/哑金点缀，与任务1 高饱和色板形成明确色感差异；
  5. **传承与差异**：立轴挂轴架构（绦带 + 天/地杆 + 竖向画幅 + K 线 + 周期刻度）传承自 02 清晰可辨，同时 5 版与 02、5 版彼此之间差异明显（母题/墨阶/装饰/构图不同）；
  6. 整体气质契合河图体系"秩序图谱、规律抽象"定位，水墨强化不减损"量化投研"业务属性。

  **C. 流程验收（硬门禁/编排器固化）**：
  1. 单元测试全部通过并写入 `.gate.json`（`test_passed=true`）；
  2. 评审 APPROVE；研发日志、资产沉淀、钉钉通知依次完成；
  3. 产出统一归档到任务目录 `opencode_schedule/20260804/20260804任务2河图Logo水墨优化/`；
  4. **不修改任务1 任何文件**（`hetu_logo_01~05.svg`、任务1 单测、任务1 任务书等保持原状）。

### 4.1 二期低饱和色板（全 5 文件强制一致，8 色封顶）

> 设计原则：任务1 色板（宣纸米白 `#F6F1E5`、墨黑 `#1C1C22`、玄青 `#264653`、朱砂 `#B33A2E`、鎏金 `#C0A062`、玄灰 `#9AA0A6`）整体降饱和、降明度对比，墨色改暖黑灰（非纯黑），点缀改灰调低饱和色。

| 角色 | 色名 | 精确 hex | 用途 |
|------|------|----------|------|
| 底色 | 淡赭纸 | `#F3E9D6` | 画布底 / 卷面底 / 留白背景（比任务1 米白更暖、带赭调） |
| 墨一 | 焦墨 | `#3B3733` | 滚筒主体、画幅主轮廓、最重笔触（K 线起笔/实体深部） |
| 墨二 | 重墨 | `#57504A` | 画幅描边、阴线实体、远山中层、绦带 |
| 墨三 | 淡墨 | `#8D8578` | 远山、晕染中层、K 线影线、网格刻度弱化线 |
| 墨四 | 清墨 | `#B7AFA2` | 水纹、云雾、最淡笔触（K 线收笔淡出）、飞白层 |
| 点缀 | 黛青 | `#4E5D66` | 阴线、远山青黛层、刻度（替代任务1 高饱和玄青 `#264653`） |
| 点缀 | 淡朱砂 | `#A96B5F` | 阳线、印章、点睛（替代任务1 朱砂 `#B33A2E`，灰调低饱和） |
| 点缀 | 哑金 | `#A9976B` | 轴头、绦带饰、高光线（替代任务1 鎏金 `#C0A062`，哑光低饱和） |

**颜色纪律**（对应 A7）：
- `fill`/`stroke` 引用的所有颜色（含 `#RRGGBB`/`#RGB`/`rgb()`）**必须** ∈ 上表 8 色；`stop-color` 同样限取色板 8 色；
- **墨阶浓淡允许用 opacity 分层模拟**（同一墨色不同 `opacity`，如焦墨 1.0 / 0.7 / 0.4 模拟焦/浓/重），`opacity` 不计入颜色计数——这是 8 色限制下实现"五色墨阶"的主要手段；
- 渐变全部内联 `<linearGradient>/<radialGradient>`，`id` 前缀统一 `grad-`，`stop-color` 限取色板 8 色；`url(#grad-xxx)` 引用登记为 1 种颜色计入 A6 计数；每文件渐变 ≤ 2 个；
- 单文件去重颜色 token（A6 口径）≤ 8：8 色板 + ≤2 渐变引用，即单文件实际 ≤ 10 个 token 时须减色——**每个文件自行在色板内取舍，保证 ≤ 8**（例：不用哑金的文件即少 1 色）。

### 4.2 K 线毛笔手绘实现规范（对应 A9、B2）

- **载体**：K 线影线与实体**必须**使用 `<path>` 承载（至少 1 个 `<path>`，见 A9）；禁止全部用几何 `<rect>`+`<line>` 直边拼装；
- **笔锋模拟**（三选一或组合，推荐①+③）：
  1. **分段 stroke**：一根影线拆 2~3 段 path，逐段降 `stroke-width`（如起笔 2.6 → 中段 1.6 → 收笔 0.8）模拟"起笔重、收笔轻"；实体两端用圆头/斜切让边缘不齐；
  2. **笔刷 path 填充**：用闭合 path（宽头 + 细尾 + 微弯侧边）填充实体，模拟毛笔拖行痕迹；
  3. **opacity 分层**：同一 path 叠加 2 层（主层全墨、尾层低 opacity 淡出），模拟墨色由浓到淡的渗化；
- **形态保持**：蜡烛结构（上下影线 + 中间实体、阳/阴区分）必须可辨识；实体宽度 6~10px（500 画布）、影线超出实体 8~20px；7 根 K 线保留 02 的"波动上行"叙事（可微调为 5~7 根，建议保持 7 根与 02 传承一致）；
- **笔触禁区**：不得出现完全水平/垂直的机械直边 K 线（实体与影线允许轻微倾斜/弯曲 ≤4°）；不得使用虚线笔触（`stroke-dasharray` 禁用，破坏手绘感）；
- 线帽：笔触 path 用 `stroke-linecap="round"`；手绘基准线宽参考：起笔 2.2~2.6、中段 1.4~1.8、收笔 0.6~1.0（500 画布）。

### 4.3 滚筒（天/地杆）加大规范（对应 A8、B3）

- **口径定义（A8 断言基准）**：取 `scroll-roll` 分组内天/地杆滚筒主体（`<rect>` 的高度或 `<path>` 的平均厚度）为**轴向厚度 T**；取 `scroll-body` 分组内主画幅矩形的**宽度 W**；要求 **0.08 ≤ T/W ≤ 0.14**；
- 参考值（500 画布、画幅宽 180 与 02 同构时）：T ∈ [14.4, 25.2]px，建议取 16~22px（02 基准为 12px，占 6.7%，本轮显著加大）；
- **圆柱立体感**：滚筒用轴向渐变（如 `grad-roll`：焦墨 → 重墨 → 淡墨高光线）或叠加 1 条高光细线（清墨/哑金，opacity 0.5）表达圆柱曲面；滚筒两端可加**轴头装饰**（哑金/重墨圆头帽，超出滚筒主体 2~4px）；
- **绦带**：顶部绦带（挂环 + 挂绳 + 垂穗）保留或加粗（02 中为 L1.5 细线，本轮建议挂绳 2.4~3、垂穗加宽），与加大滚筒视觉配比；
- 滚筒横向宽度：≥ 画幅宽（可超出 4~10px 呈"轴出卷面"形态，增强挂轴真实感）。

### 4.5 通用规格（沿用任务1 并做水墨化调整）

- **画布**：`viewBox="0 0 500 500"`（与 02 一致，传承优先；允许个别版本用 `0 0 1024 1024` 且宽高相等），`width="100%" height="100%"`，`role="img"`，`aria-label="河图"`；
- **SVG 根标签统一**：`<svg xmlns="http://www.w3.org/2000/svg" viewBox="..." width="100%" height="100%" role="img" aria-label="河图">`；
- **分组约定**：`scroll-roll` / `scroll-body` / `scroll-ribbon` 必含（A5）；`quant-kline` / `quant-scale` 建议含（评审核对）；`id` 全局唯一；
- **留白**：主图形区约占画布 55%~65%，四周留白 ≥ 95px（19%）——水墨留白是本组灵魂，允许比任务1 更大（图形区可降至 50%）；
- **文本**：默认不使用文字；确需印章文字/落款时 `font-family` 仅限安全字体族（`serif`/`SimSun`/`KaiTi` 等），禁外部字体文件；**推荐印章以块面+留白示意，不使用真实文字**（规避字体依赖）；
- **水墨质感技巧（可选池）**：背景淡赭纸上可叠加 1~2 层大半径低 opacity（≤0.08）淡墨圆形"晕染渍"；画幅边缘"渗墨"用 2~3px 锯齿 path 模拟；禁止位图/滤镜（`filter` 均允许内联，但**禁用 `feImage` 外链**，推荐不依赖滤镜，纯 path 表现）。
