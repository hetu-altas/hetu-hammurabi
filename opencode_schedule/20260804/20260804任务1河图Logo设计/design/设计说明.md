## 一、设计背景与总体意图

河图体系由 hetu-aether（河图·以太，量化数据处理基础设施）、hetu-mercury（河图·墨丘利，金融市场数据接口管理）、hetu-thoth（河图·透特，投研非结构化数据处理）与 hetu-hammurabi（宪章编程 harness）构成，是量化投研基础设施体系。体系座右铭"**河出图，洛出书，圣人则之**"——河图即宇宙秩序图谱、万物规律抽象。

Logo 设计以四重约束为纲，五个方案共享同一视觉基因：

1. **卷轴母题**：卷轴（轴杆 / 卷面 / 画幅 / 绦带）呼应"河图 = 图谱、典册"，是"秩序被书写、被展开"的意象载体；
2. **中式极简**：宣纸米白底 + 墨黑/玄青主色 + 朱砂/鎏金点睛，大量留白（四周 ≥ 19%）、线条克制、构图对称或均衡；
3. **科技感**：点阵网格、数据轨迹、渐变描边发光、几何精确排布，表达数字化基础设施属性；
4. **量化要素**：K 线 / 点阵 / 趋势曲线 / 回测网格 / 周期刻度，呼应量化投研业务；其中"河图五方点阵"直接演绎座右铭。

## 二、统一设计规范（5 文件强制一致）

### 2.1 主色板（6 色 + 渐变引用）

| 角色 | 色名 | 精确 hex | 用途 |
|------|------|----------|------|
| 底色 | 宣纸米白 | `#F6F1E5` | 画布底 / 卷面底 / 留白背景 |
| 主色 | 墨黑 | `#1C1C22` | 轴杆、主轮廓 |
| 辅主色 | 玄青 | `#264653` | 画幅描边、深色块、阴线、主网格 |
| 点缀 | 朱砂红 | `#B33A2E` | 阳线、上升箭头、中心点、印章点睛 |
| 点缀 | 鎏金 | `#C0A062` | 轴头、光晕（方案 3/4/5） |
| 辅助 | 玄灰 | `#9AA0A6` | 弱化网格 / 刻度（方案 5） |

**渐变约定**：全部内联 `<linearGradient>`，`id` 前缀统一 `grad-`；`stop-color` 仅取自主色板；渐变以 `fill/stroke="url(#grad-xxx)"` 引用，每文件渐变 ≤ 2 个。`url(#...)` 引用登记为 1 种颜色计入 A6 计数，`stop-color` 不单独计入。

### 2.2 通用规格

- 画布：`viewBox="0 0 500 500"`，`width="100%" height="100%"`，`role="img"`，`aria-label="河图"`；
- 线宽体系：L1 = 1.5（网格/刻度/细线）、L2 = 3（主轮廓/曲线/折线）、L3 = 6（轴杆级别，本组以 10~12px 圆角柱表达）；轨迹/轴杆 `stroke-linecap="round"`，网格 `square`；
- 留白：主图形区约占画布 56%~62%，四周留白 ≥ 95px（19%）；图形内部元素间距 ≥ 15px；
- 分组约定：卷轴元素全部包入 `id="scroll-` 开头分组（必含）；量化元素包入 `id="quant-` 开头分组（建议）；
- 无文本元素、无外部资源（自包含）。

## 三、五个方案详述

### 方案 1｜`hetu_logo_01.svg` —— 半展开横卷 · 河图五方点阵

**构图摘要**：横向均衡构图。一幅半展开的横卷居中铺陈（280×230，占画布 56% 宽），左右两根墨黑轴杆垂直立定，卷面内是"河图五方点阵"——中心朱砂大点统摄四方，南 2 / 东 3 / 西 4 / 北 5 组玄青星点布列五方，底衬 3×3 细点阵网格。

**要素映射**：

| 设计约束 | 承载元素 |
|----------|---------|
| 卷轴意象 | `scroll-roll`（双轴杆）、`scroll-body`（横卷画幅 + 卷层细线） |
| 中式极简 | 米白底、仅 4 色 + 1 渐变、对称轴杆、留白充足 |
| 科技感 | 细点阵网格底纹、朱砂中心点渐变光晕（`grad-glow`） |
| 量化要素 | **河图五方点阵**（点阵量化母题，呼应"河出图"） |

**意涵**：五方星点数序（2-3-4-5）取意五行生成之数，中央一点统摄四方，象征河图"居中驭四方"的秩序图谱；半展开的画卷暗示"规律正在被展开、被读解"。

**适用场景**：品牌主标识（全尺寸、白底）、文档封面、体系发布会主视觉。

---

### 方案 2｜`hetu_logo_02.svg` —— 立轴挂轴 · 画幅内嵌 K 线

**构图摘要**：竖向构图。天杆 / 地杆分列上下，顶部绦带（挂环 + 挂绳 + 垂穗）点睛，玄青→墨黑渐变描边的竖向画幅内排布 7 根 K 线蜡烛（阳线朱砂、阴线玄青），画幅底部带周期刻度基线。

**要素映射**：

| 设计约束 | 承载元素 |
|----------|---------|
| 卷轴意象 | `scroll-ribbon`（绦带）、`scroll-roll`（天/地杆）、`scroll-body`（立轴画幅） |
| 中式极简 | 米白底、4 色 + 1 渐变、挂轴式经典比例（画幅宽高 180:264） |
| 科技感 | 画幅描边渐变描边（`grad-scroll`）、K 线几何精确排布 |
| 量化要素 | **K 线蜡烛图**（7 根、波动上行）+ **周期刻度**短线 |

**意涵**：挂轴是典册悬挂之形，"图卷高悬、数据如烛"——把市场波动装裱进典籍画幅，直指量化投研"以数据著书"的气质。

**适用场景**：纵向版面（名片竖版、App 图标、印章形制）、展览竖幅、PPT 封面竖排场景。

---

### 方案 3｜`hetu_logo_03.svg` —— 完全展开横幅 · 数据轨迹线

**构图摘要**：横向动势构图。横幅完全展开（280×180），左右圆角卷杆带上下鎏金轴头；一条玄青→墨黑渐变轨迹曲线自左下穿过两次小回调攀升至右上，朱砂上升箭头点睛，横幅下方两道鎏金→米白光晕横线。

**要素映射**：

| 设计约束 | 承载元素 |
|----------|---------|
| 卷轴意象 | `scroll-body`（完全展开横幅 + 卷层线）、`scroll-roll`（双卷杆 + 鎏金轴头） |
| 中式极简 | 米白底、5 色 + 2 渐变、单条主曲线、留白集中于上下 |
| 科技感 | 轨迹渐变描边发光（`grad-trend`）、底部鎏金光晕（`grad-glow`） |
| 量化要素 | **趋势曲线**（带回调的上升轨迹）+ **上升箭头** |

**意涵**：完全展开的横幅 = "全谱系图谱"，上扬轨迹曲线直指"规律在波动中被发现、趋势在数据中显形"，是全体系中最具"行进感"的方案。

**适用场景**：宽幅 Banner、官网首页 Hero、体系周年 / 发布活动视觉。

---

### 方案 4｜`hetu_logo_04.svg` —— 双轴杆坐标柱 · 波动折线

**构图摘要**：对称均衡构图。左右两根墨黑轴杆兼作折线图坐标柱（上端卷曲纸边 + 鎏金轴头），左轴内侧 7 条周期刻度短线，两柱之间一条玄青→墨黑渐变折线上下波动后上行，7 个朱砂数据节点圆点标记折点。

**要素映射**：

| 设计约束 | 承载元素 |
|----------|---------|
| 卷轴意象 | `scroll-roll`（双轴杆 = 坐标柱，上端卷曲纸边、鎏金轴头） |
| 中式极简 | 米白底、5 色 + 1 渐变、两柱夹一线的极简构图 |
| 科技感 | 坐标刻度系统、渐变描边折线、几何精确排布 |
| 量化要素 | **波动折线图**（折线母题）+ **数据节点点阵** + 周期刻度 |

**意涵**：轴杆与坐标柱同构——"卷轴即坐标系"，把典籍的轴与数据的轴合而为一，暗示"河图是度量万物规律的坐标"。

**适用场景**：产品文档体系（aether / mercury / thoth 各子项目图标）、数据产品入口、中性底色环境。

---

### 方案 5｜`hetu_logo_05.svg` —— 对称双卷 · 回测经纬网格

**构图摘要**：严格轴对称构图。左右镜像双卷杆（上下鎏金轴头）夹持中央画幅（200×220），画幅内嵌 40px 玄青主网格 + 20px 玄灰细分弱网格（10×10 经纬回测网格），底部 5 个刻度圆点与主网格列对齐，网格中央朱砂圆点 + 鎏金光晕为规则中枢。

**要素映射**：

| 设计约束 | 承载元素 |
|----------|---------|
| 卷轴意象 | `scroll-roll`（左右镜像双卷杆）、`scroll-body`（中央展开画幅） |
| 中式极简 | 米白底、6 色 + 1 渐变、绝对对称构图（镜像于 x=250） |
| 科技感 | 双层等距经纬网格、鎏金中心光晕（`grad-glow`） |
| 量化要素 | **回测网格**（等距经纬网格）+ **周期刻度点** |

**意涵**：回测网格是量化研究的方法论底色——在网格中反复验证规律；双卷对称如"左图右书"，中央朱砂一点如"圣人则之"的落笔处，是全组最具"方法论秩序感"的方案。

**适用场景**：体系总览页、技术白皮书封面、需要强秩序感的正式场合。

## 四、方案差异矩阵（B6 核验：非同图微调）

| 维度 | 方案1 | 方案2 | 方案3 | 方案4 | 方案5 |
|------|-------|-------|-------|-------|-------|
| 构图方向 | 横向均衡 | 竖向立轴 | 横向动势 | 两柱夹线对称 | 严格轴对称 |
| 卷轴形态 | 半展开横卷 + 双轴杆 | 挂轴式（天/地杆 + 绦带） | 完全展开横幅 + 卷曲轴杆 | 轴杆兼坐标柱 + 卷曲纸边 | 对称双卷 + 中央画幅 |
| 量化母题 | 河图五方点阵 | K 线蜡烛图 | 趋势曲线 + 上升箭头 | 波动折线 + 数据节点 | 回测经纬网格 |
| 科技感元素 | 点阵网格 + 中心光晕 | 渐变描边 + 周期刻度 | 轨迹渐变发光 + 底部光晕 | 坐标刻度系统 | 双层网格 + 鎏金光晕 |
| 点缀手法 | 朱砂中心大点 | 朱砂/玄青阴阳 K 线 | 朱砂上升箭头 | 朱砂节点点阵 | 朱砂中心点 + 鎏金光晕 |

三轴（构图方向 / 卷轴形态 / 量化母题）在 5 方案中两两不同，互不构成同图微调。

## 五、推荐意见

- **首选主标识**：**方案 1**（半展开横卷 · 河图五方点阵）。理由：卷轴意象最直观完整（轴杆 + 画幅俱全），"河图五方点阵"直接演绎座右铭"河出图"，文化与业务双重叙事最饱满，且 5 色最克制、缩放适应性最好（大点小点层级清晰）。
- **备选主标识**：方案 3（横幅 + 轨迹曲线），动势与科技感最强，适合传播场景；方案 5（双卷 + 回测网格）秩序感最强，适合正式/方法论场景。
- **子品牌延展建议**：hetu-aether / hetu-mercury / hetu-thoth 三个业务项目可分别沿用方案 4 的"坐标柱"结构（更换点缀色阶）或方案 2 的立轴形制（更换 K 线配色），保持"卷轴基因"统一。
- **落地注意**：SVG 原件归档于任务目录 `design/`；正式选定时建议在深色底上增加白色反白版（本组色板针对米白底设计）。
