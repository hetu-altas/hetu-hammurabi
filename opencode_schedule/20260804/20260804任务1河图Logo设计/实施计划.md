## 一、任务概述与验收标准

### 1.1 任务概述

为河图体系（hetu-aether / hetu-mercury / hetu-thoth / hetu-hammurabi）设计品牌 Logo 的 **5 个备选 SVG 方案**，附设计说明与单元测试。核心设计约束 4 项（缺一不可）：

1. **卷轴意象**：以卷轴为母题（轴杆 / 卷面 / 画幅 / 绦带），呼应"河图=图谱、典册"；
2. **中式极简**：大量留白、克制线条色块、对称或均衡构图；
3. **科技感**：网格点阵、数据轨迹、渐变发光描边、几何精确排布；
4. **量化要素**：K 线 / 点阵 / 趋势曲线 / 回测网格 / 上升箭头 / 周期刻度中至少融入 1~2 种，推荐结合"河图五方点阵"呼应座右铭"河出图，洛出书，圣人则之"。

### 1.2 验收标准（三类）

**A. 交付物硬门禁（可被单测断言）**

| # | 标准 | 断言要点 |
|---|------|---------|
| A1 | `design/` 下恰好 5 个 SVG（`hetu_logo_01.svg`~`hetu_logo_05.svg`）+ 1 份 `设计说明.md` | 文件名精确匹配、数量=5 |
| A2 | 每个 SVG 合法 XML，根元素 `<svg>`，标签闭合配对 | `ET.fromstring` 可解析 |
| A3 | `viewBox="0 0 500 500"` 或 `0 0 1024 1024"`（宽高相等），width/height 与 viewBox 比例一致 | viewBox 4 元组、w==h |
| A4 | 自包含：无 `<image>`、无 `url(` 外链、无 `<link>`/`@import`；字体仅安全字体族 | 元素扫描 + 正则 |
| A5 | 卷轴元素统一放入 `id="scroll-"` 开头分组 `<g>` | 每文件 ≥1 个 |
| A6 | `fill`/`stroke` 去重颜色（含 `#RRGGBB`/`#RGB`/`rgb()`/`url(#渐变)`）≤ 8 | 去重计数 ≤ 8 |
| A7 | 5 方案共享同一主色板（墨黑/玄青主色、朱砂或金点缀、宣纸米白底），色值全文件一致 | 见 §3.1 固化色值 |

**B. 设计质量软门禁（节点4 人工评审）**：卷轴一眼可辨且与科技元素融合自然；极简留白；科技感至少其一；量化要素至少其一；气质契合"秩序图谱、规律抽象"；5 方案构图/母题差异明显（非同图微调）。

**C. 流程硬门禁（编排器固化）**：单测全通过并写 `.gate.json`（`test_passed=true`）→ 评审 APPROVE → 日志 → 资产沉淀 → 钉钉通知。

## 三、技术方案要点

### 3.1 设计规范固化（全 5 文件强制一致）

**主色板（6 色 + 2 渐变引用，单文件用量 ≤ 8）**

| 角色 | 色名 | 精确 hex | 用途 |
|------|------|----------|------|
| 底色 | 宣纸米白 | `#F6F1E5` | 画布底/卷面底/留白背景 |
| 主色 | 墨黑 | `#1C1C22` | 轴杆、主轮廓、文字（若有） |
| 辅主色 | 玄青 | `#264653` | 画幅描边、深色块、阴线、网格 |
| 点缀 | 朱砂红 | `#B33A2E` | 阳线/上升箭头/中心点/印章点睛 |
| 点缀 | 鎏金 | `#C0A062` | 轴头、光晕、金线（方案3/4/5 使用） |
| 辅助 | 玄灰 | `#9AA0A6` | 弱化网格/刻度（方案5 等按需，可省） |

**渐变定义方式**：全部使用内联 `<linearGradient>`，`id` 前缀统一 `grad-`（如 `grad-scroll`、`grad-glow`、`grad-trend`）；`stop` 的 `stop-color` 只允许取自主色板 6 色；渐变以 `fill="url(#grad-xxx)"` / `stroke="url(#grad-xxx)"` 引用，**url 引用登记为一种颜色**计入 A6 计数。禁止 `radialGradient` 之外的自定义复杂渐变（保持极简）；每文件渐变数量 ≤ 2。

**线宽体系**（stroke-width，单位 px，500 画布基准）：
- `L1 = 1.5`：网格线、周期刻度、点阵细线
- `L2 = 3`：主轮廓、画幅边框、数据曲线
- `L3 = 6`：轴杆、重点强调元素
- 线帽约定：轨迹/轴杆 `stroke-linecap="round"`；网格 `square`；`stroke-linejoin="round"`

**留白比例建议**：画布 500×500（或 1024×1024 等比）下，主图形外接矩形建议占画布 **55%~65%**（500 画布对应图形区约 x∈[95,405]、y∈[95,405]，四周留白 ≥ 95px ≈ 19%）；图形内部元素间距 ≥ 15px 安全距离；同一文件内网格间距统一（如 40px 或 80px 整数倍）。

**文本约定**：默认不使用文本元素；确需时 `font-family` 仅限 `serif / sans-serif / monospace / SimSun / KaiTi / FangSong` 等安全字体族，禁外部字体文件。

**SVG 根标签统一**：`<svg xmlns="http://www.w3.org/2000/svg" viewBox="..." width="100%" height="100%" role="img" aria-label="河图">`。

### 3.3 每个 SVG 的结构规划（统一骨架）

```
<svg ... viewBox="0 0 500 500" width="100%" height="100%" role="img" aria-label="河图">
  <defs>
    <linearGradient id="grad-scroll" x1="0" y1="0" x2="1" y2="0">  <!-- 玄青→墨黑 描边渐变 -->
      <stop offset="0%" stop-color="#264653"/><stop offset="100%" stop-color="#1C1C22"/>
    </linearGradient>
    <linearGradient id="grad-glow" ...>...</linearGradient>         <!-- 发光点缀，可选 -->
  </defs>
  <rect id="bg-paper" x="0" y="0" width="500" height="500" fill="#F6F1E5"/>
  <g id="scroll-roll">    <!-- 轴杆：L3 线条 + 鎏金轴头，必含 scroll- 前缀 -->
  <g id="scroll-body">    <!-- 卷面/画幅：L2 边框 -->
  <g id="quant-grid">     <!-- 网格/刻度：L1 细线（量化要素，建议 quant- 前缀） -->
  <g id="quant-dots">     <!-- 点阵/数据节点（按方案取舍） -->
  <g id="quant-kline|quant-trend|quant-line">  <!-- K线/曲线/折线：L2 渐变描边 -->
  <g id="accent">         <!-- 朱砂点睛/上升箭头 -->
</svg>
```

分组约定（对应 A5 与任务书第四节）：
- **必含**：`id="scroll-` 开头的 `<g>` 分组 ≥ 1 个（轴杆/卷面/绦带全部包入）；
- **建议含**：量化元素包入 `id="quant-` 开头的分组（不强制作断言，便于评审核对）；
- 每文件渐变 ≤ 2、`id` 全局唯一、颜色全部取自 §3.1 色板。

**单文件配色表样例（方案3，7 色 ≤ 8）**：`#F6F1E5`、`#1C1C22`、`#264653`、`#B33A2E`、`#C0A062`、`url(#grad-trend)`、`url(#grad-glow)`。其余方案依 §3.2 色彩分配列控制在 5~8。

## 五、风险与注意事项

| # | 风险 | 规避措施 |
|---|------|---------|
| 1 | XML 手写易错（标签不闭合、属性引号缺失、`&` 未转义） | 每产出 1 个 SVG 立即 `ET.parse` 自检；本任务无文本元素，`&` 转义风险基本为零；属性统一双引号 |
| 2 | 颜色计数口径偏差（`url(#渐变)` 是否计入、`stop-color` 是否计入、`style="fill:..."` 漏计） | 按任务书 A6 口径：仅统计 `fill`/`stroke` 属性（含 style 内联），`url(#x)` 记 1 种，`none` 不计；`stop-color` 不计入但限制取自主色板；测试用 `_collect_color_tokens` 统一口径 |
| 3 | 命名空间导致断言失效（`ET` 解析后 tag 为 `{ns}svg`） | tag 判定用 `endswith("svg")`；查找元素用遍历 + localname 比较，不用 XPath（避免命名空间映射复杂度） |
| 4 | viewBox 分隔符不统一（逗号/空格） | 5 文件统一空格分隔；测试 `re.split(r"[ ,]+")` 兼容 |
