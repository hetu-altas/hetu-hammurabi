## 一、任务概述

为 hetu 系列量化投研基础设施体系（hetu-aether / hetu-mercury / hetu-thoth / hetu-hammurabi）设计品牌 Logo 的 **5 个备选 SVG 方案**，并附设计说明与合规性单元测试，供后续选定主标识。

- **任务性质**：品牌设计资产类任务（非业务代码库任务），纯静态 SVG 产物，无数据库读写、无网络调用、无接口依赖；
- **需求背景**：体系座右铭"河出图，洛出书，圣人则之"——河图即宇宙秩序图谱、万物规律抽象；体系长期缺乏统一品牌视觉标识；
- **交付目标**：`design/` 下恰好 5 个自包含 SVG（`hetu_logo_01.svg` ~ `hetu_logo_05.svg`）+ 1 份 `设计说明.md`，通过单测硬门禁与评审软门禁后归档于任务目录；
- **流程节点**：节点 -1 任务书生成 → 节点 0 校验 → 节点 1 分析（实施计划）→ 节点 2 编码（5 SVG + 设计说明）→ 节点 3 单元测试（10/10 通过）→ 节点 4 评审（APPROVE）→ **节点 5 研发日志（本文）**。

## 二、需求要点（4 项设计约束，缺一不可）

| # | 约束 | 要求 |
|---|------|------|
| 1 | **中国传统卷轴意象** | 以卷轴（画轴 / 展开卷轴画幅 / 轴杆）为核心视觉母题，呼应"河图=图谱、典册" |
| 2 | **中式极简风格** | 大量留白、克制线条与色块、对称或均衡构图，避免繁复装饰 |
| 3 | **科技感** | 网格点阵、数据轨迹线、发光 / 渐变描边、几何精确排布，体现数字化与基础设施属性 |
| 4 | **量化投资要素** | 至少融入 K 线 / 数据点阵 / 趋势曲线 / 回测网格 / 上升箭头 / 周期刻度中的 1~2 种；推荐结合"河图五方点阵"呼应座右铭 |

**验收标准三类**：A 类交付物硬门禁 7 项（可单测断言：文件数量与命名、XML 合法、viewBox 合规、自包含、卷轴分组 `id="scroll-"`、去重颜色 ≤ 8、5 方案共享主色板）；B 类设计质量软门禁 6 条（节点4 人工判定）；C 类流程硬门禁（单测通过写 `.gate.json` → 评审 APPROVE → 日志 → 资产沉淀 → 钉钉通知）。

## 五、核心设计（设计要点）

### 5.1 统一色板与规范（全 5 文件强制一致）

| 角色 | 色名 | 精确 hex | 用途 |
|------|------|----------|------|
| 底色 | 宣纸米白 | `#F6F1E5` | 画布底 / 卷面底 / 留白背景 |
| 主色 | 墨黑 | `#1C1C22` | 轴杆、主轮廓 |
| 辅主色 | 玄青 | `#264653` | 画幅描边、深色块、阴线、主网格 |
| 点缀 | 朱砂红 | `#B33A2E` | 阳线、上升箭头、中心点、印章点睛 |
| 点缀 | 鎏金 | `#C0A062` | 轴头、光晕（方案 3/4/5） |
| 辅助 | 玄灰 | `#9AA0A6` | 弱化网格 / 刻度（方案 5） |

- **通用规格**：`viewBox="0 0 500 500"` + `width="100%" height="100%"` + `role="img"` + `aria-label="河图"`；线宽 L1=1.5 / L2=3 / L3=6（轴杆以 10~12px 圆角柱表达）；主图形区占画布 56%~62%，四周留白 ≥ 95px（19%）；无文本元素；自包含（无位图 / 外链 / 外部字体）；
- **分组约定**：卷轴元素全部包入 `id="scroll-` 分组（scroll-roll / scroll-body / scroll-ribbon，必含）；量化元素包入 `id="quant-` 分组（dots / kline / trend / line / grid / scale，建议）；渐变内联 `<linearGradient>`、id 前缀 `grad-`、每文件 ≤ 2 个、`stop-color` 仅取自主色板、`url(#...)` 引用计入颜色数。
