## 一、任务概述与验收标准

### 1.1 任务概述

前两期 SVG 矢量方案（任务1 极简系列 01~05、任务2 水墨强化系列 06~10）已评审通过，但用户评估矢量效果不足，转向 **AIGC 文生图路线**生成 logo 底稿。本任务为该路线的前置提示词工程：产出一份**可直接投喂主流文生图模型（Midjourney / DALL·E / Stable Diffusion / 通义万相）**的提示词工程文档，覆盖用户 4 项核心要求：

1. **横向卷轴画卷**（延续任务1 方案1/3 横向卷轴基因）；
2. **画卷上是水墨风 K 线图**（毛笔笔触、蜡烛形态可辨）；
3. **一个曲折向上的红色箭头**（延续任务1 方案3 朱砂上升箭头母题）；
4. **极简中国水墨风**（宣纸底 + 墨色晕染 + 大量留白 + 克制用色）。

**边界**：本任务只产出文档与文档断言单测，**不实际调用任何文生图模型出图**；实测生成由用户后续自行安排。

### 1.2 验收标准（A/B/C 三类，全部满足）

- **A 类（硬门禁，15 用例，单测对象为 markdown 文本内容断言）**：见任务书第七节 15 条，本计划第三节逐条细化断言逻辑；
- **B 类（评审软门禁 6 条）**：8 段结构完整可投喂；与一二期视觉基因一致（卷轴母题/朱砂点睛/留白气韵/K线+上升箭头）；5 变体差异明显；负面提示词完备可扩展；英文版非机翻生硬堆词；使用说明可落地；

#### 3.1.2 英文对照翻译策略（两种形态，对应 A7）

1. **MJ 风格词形态**（可直接附在 MJ 提示词末尾）：主词 + 风格描述词短语，如 `horizontal chinese ink painting scroll, centered composition, minimalist sumi-e style, rice paper texture, one vermilion red arrow curving upward, brush-drawn candlestick k-line chart, lots of negative space, no text`。用逗号分隔短语而非完整句，符合 MJ 权重语法习惯；禁止生硬逐字翻译。
2. **SD tag 形态**（标注"SD 风格可将其拆分为 tag 并以逗号分隔输入 positive"）：`horizontal scroll, rice paper, ink wash, sumi-e, candlestick chart, k-line, red arrow, rising trend, minimalism, negative space, flat lighting`，负面提示词进 negative 框。

#### 3.1.6 使用说明章节结构（A10）

1. **模型适配表**：MJ / SD / DALL·E 3 / 通义万相 4 模型全覆盖（≥2 即达标）——各自的投喂方式（MJ 英文主提示词+参数后缀；SD positive/negative 分框 + CFG；通义万相中文直投 + 参数面板）、参数写法差异对照；
2. **翻车规避清单**（≥3 类，实际写 5 类）：
   - ①文字乱码：负向加 `no text`，画面描述禁用字形词（"写几个字"等）；
   - ②元素拼贴/割裂：元素种类克制 ≤5 类、构图词用"居中/单主体"；
   - ③风格不统一：统一墨阶与用色词、避免中英混写与多风格并列词；
   - ④K 线被读成条形码（鼓励项）：加 `hand-drawn candlestick` 类词；
   - ⑤红色箭头过细被吞（鼓励项）：加 `bold`/朱砂色词。

## 五、风险与注意事项

| 风险 | 等级 | 规避措施 |
|------|------|----------|
| **正则误匹配/漏匹配**（如 `K线` vs `K 线`、大小写、`横向`+`卷轴` AND 关系写错） | 高 | 锚点统一 `re.IGNORECASE`；`K\s*线` 兼容空格；AND 关系拆两个独立断言；锚点断言限定主提示词章节文本（先 `_extract_section` 再匹配），防全文误命中 |
| **长度口径歧义**（中文按字符还是字节；是否去空白） | 中 | 统一 `re.sub(r'\s','',text)` 后 `len()`（Python 字符计）；目标 280~330 字，远离 100/500 边界留缓冲 |
| **模型参数表述不准确**（MJ `--v` 版本号、SD 采样器、通义万相选项随版本变动） | 中 | 文中标注"以模型官方最新文档为准"；参数给范围/建议值而非断言精确值；单测只断言宽高比与 stylize 关键词，不断言具体数值 |
| **与一二期意象不一致**（B3 传承项） | 高 | 红色箭头沿用任务1 方案3"带回调攀升"语义（`蜿蜒折返后攀升`）；印章变体对齐任务2 10 号淡朱砂方印（36×36 落款）；色板引用任务2 低饱和三色（淡赭纸 #F3E9D6 / 焦墨 #3B3733 / 淡朱砂 #A96B5F），**不得混入任务1 高饱和色板数值** |
| **单测污染 design/ 目录**（破坏 A12 断言） | 高 | 反/边界一律 tempfile 临时目录 + tearDown 清理，严禁写入 `design/`；A12 同时断言 `.svg` 与 `.xml` 双空 |
| **只读约束被破坏**（误改任务1/2 文件、误产出 SVG） | 高 | 编码节点只写本任务目录内文件；交付物为纯 markdown，无任何设计文件格式 |
| **敏感词误伤正文**（黑名单词与正文词交集） | 低 | 黑名单选用与正文用词零交集的明确违规词（见 3.3 清单），编码后跑 A11 验证 |
| **章节标题命名漂移**（与单测前缀不匹配） | 中 | 文档章节名与单测前缀在编码前锁定：`## 主提示词/英文提示词/负面提示词/参数建议/变体微调方向/使用说明`；单测按前缀匹配容忍"变体微调方向"等扩展命名 |
