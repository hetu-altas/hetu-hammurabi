## 一、任务概述

本任务为河图品牌设计资产类任务**第三期（文生图提示词工程）**：前两期（任务1 极简系列 01~05、任务2 水墨强化系列 06~10）均为 SVG 矢量方案并已评审通过，但**用户评估 SVG 矢量方案整体效果不足**，决定转向 **AIGC 文生图路线**生成 logo 底稿（由主流文生图模型出图，后续再考虑矢量重绘/人工精修）。本任务为该路线的**前置提示词工程**：产出一份**可直接投喂主流文生图模型（Midjourney / DALL·E 3 / Stable Diffusion / 通义万相）的提示词工程文档**。

- **任务性质**：品牌设计资产类任务（非业务代码库任务），**纯文档产出**——无 SVG 产出、无数据库/网络调用、不实际调用任何文生图模型出图（实测生成与效果回评由用户后续自行安排）；
- **需求背景**：SVG 矢量效果评估不足 → 转向 AIGC 路线；提示词延续"卷轴母题 + 量化要素（K 线/上升箭头）+ 中式极简"视觉基因，与任务1/任务2 已有资产语义对齐；
- **交付目标**：`design/河图Logo文生图提示词.md`（6 章节、最终 194 行）+ 文档文本断言单测 15 用例，通过 A/B/C 三类验收后归档于任务目录；
- **流程节点**：节点 -1 任务书生成 → 节点 1 分析（实施计划）→ 节点 2 编码（提示词文档）→ 节点 3 单元测试（15/15 通过）→ 节点 4 评审（**第1轮 REVISE → charter-coder 修复 → 第2轮复审 APPROVE**）→ **节点 5 研发日志（本文）**；
- **约束红线**：任务1/任务2 目录全文件只读不改；不新增任何 `.svg`/`.xml` 设计文件（A12 硬门禁，与一二期区分的标志性断言）。

### 5.6 使用说明（A10 断言对象）

1. **模型适配表**：MJ / SD / DALL·E 3 / 通义万相 4 模型全覆盖——各自投喂方式（英文主词+参数后缀 / positive+negative 分框 / 自然语言直投 / 中文直投+面板）、参数写法差异对照；
2. **5 类翻车规避**（现象→处置一一对应）：①文字乱码（负向加 `no text`、禁用字形词）；②元素拼贴/割裂（元素 ≤5 类、构图词用"居中/单主体"、负向加 `clutter`）；③风格不统一（统一墨阶用色词、避免中英混写、负向加 `photorealistic`）；④K 线被读成条形码（加 `hand-drawn candlestick`、负向加 `no barcode`/`no grid lines`）；⑤红色箭头过细被吞（主词加 `bold vermilion arrow` 强化朱砂对比，或采用变体3 加大留白提升可见性）；
3. **3 步使用流程**：首轮多模型对比 → 变体控制变量微调 → 精选底稿矢量重绘/人工精修后与一二期 SVG 并案评估。
