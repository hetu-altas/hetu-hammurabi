## 三、技术方案要点

### a. `scripts/harness_topology.py` 函数签名与行为契约（任务书 4.2 表，6 个函数）

纯函数库，**不做任何文件写入**（仅读），输入路径参数化，无副作用，供单测与 install_harness.sh 调用。文件头按编码宪章：`# -*- coding: utf-8 -*-` + 模块级 docstring + 全量类型标注。

| 函数 | 签名 | 行为契约 |
|------|------|---------|
| `detect_host_dir` | `(workspace_dir: str) -> str` | 遍历同父目录下 `hetu-*` 前缀目录（必须为目录），判定条件 = 同时含 `.opencode/agents/`（目录）且 `constitution/constitution.md`（文件）且 `docs/资源地图.md`（文件）。多个命中时取「要件命中数最多」者（3 要件齐全优先于 2 要件），再同级按目录名升序取第一个（保证确定性输出）；无命中 → `raise ValueError`（含候选目录列表信息） |
| `list_target_projects` | `(workspace_dir: str, host_dir: str, extra: str \| None = None) -> list[str]` | 返回 `workspace_dir` 下 `hetu-*` 前缀且 `os.path.isdir` 且绝对路径 ≠ `host_dir` 的项目绝对路径列表，按名称排序；`extra` 非空时追加指定项目（若已是 hetu-* 且存在于目录则去重；`extra` 指向不存在的目录 → 忽略并在返回的跳过列表体现）。**签名返回 `(targets: list[str], skipped: list[str])` 元组**（skipped 供调用方提示「extra 指定项目不存在」），保证纯函数可断言 |
| `resolve_aether_dir` | `(workspace_dir: str) -> str \| None` | 返回 `workspace_dir/hetu-aether`（目录存在时），否则 `None`（调用方回退） |
| `resolve_venv_bin` | `(workspace_dir: str) -> str \| None` | 返回 `workspace_dir/venv-hetu/bin/python`（存在时），否则 `None` |
| `build_env_content` | `(project_dir: str, workspace_dir: str, host_dir: str) -> str` | 生成 .harness-env 文本（见 b），六字段齐全、绝对路径、含「自动生成勿手改」头注释；PROJECT_NAME 取 project_dir basename；AETHER_DIR/VENV_BIN 缺失时写空值并注释说明（缺省回退约定） |
| `parse_env_content` | `(text: str) -> dict[str, str]` | 解析 .harness-env 文本为 dict：跳过空行与 `#` 注释行；`KEY=VALUE` 拆分，支持 `KEY="带空格值"`（引号剥离）；重复键后者覆盖 |

**`--dump` 调试入口**（任务书五）：`python scripts/harness_topology.py --dump /path/to/project`——以该项目的父目录为 workspace，输出 detect_host_dir / list_target_projects / resolve_aether_dir / resolve_venv_bin 结果与 build_env_content 预览，供 install 后核查。

**边界约定**（任务书 4.2）：路径含空格 → build_env_content 输出值带引号包裹；字段值一律绝对路径（`os.path.abspath` 归一化）；PROJECT_NAME 取目录 basename。宿主与目标项目判定只认目录（文件跳过）。

### b. `.opencode/.harness-env` 字段契约（任务书 4.1）

```bash
# 由 install_harness.sh 自动生成，勿手改
PROJECT_NAME=<当前项目名，如 hetu-sybil>
PROJECT_DIR=<当前项目绝对路径>
WORKSPACE_DIR=<同父目录（所有 hetu-* 平级项目的根）绝对路径>
HARNESS_DIR=<harness 宿主项目绝对路径>
AETHER_DIR=<公共工具项目绝对路径，缺省回退：同父目录下 hetu-aether>
VENV_BIN=<共享虚拟环境 python 绝对路径，缺省回退：同父目录下 venv-hetu/bin/python>
```

- 生成时机：install_harness.sh 每次执行时**静态重写**各业务项目 `.opencode/.harness-env`（编排者决策 3）。
- 读取规则（写入全部 agents/skills 的统一措辞，见 d）：先 `cat .opencode/.harness-env` 解析；文件缺失/字段缺失时按回退规则动态查找——① 同父目录含 `constitution/` + `.opencode/agents` + `docs/资源地图.md` 的 `hetu-*` 目录为宿主；② `hetu-aether` 为公共工具项目；③ 同父目录 `venv-hetu/bin/python` 为共享环境；④ 当前目录 basename 为项目名。
