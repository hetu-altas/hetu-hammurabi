## 三、核心设计

1. **门禁信任模型（D1/D2）**：判定只认当前任务目录 `.gate.json`（run_id 契约）；
   HMAC token 覆盖 run_id + 结果摘要 + 关键声明字段；写/验分离（tester 只产 result，
   编排器 seal-gate 落闸）；10 分钟新鲜度窗口；fail-closed
2. **绕过面覆盖（D4）**：通知 URL/函数特征检测 + 唯一出口白名单；
   危险命令任意位置匹配；日志变体命名识别；审计文件（研发流程状态.md）放行（D3）
3. **流程外置（D5）**：workflow.yaml 定义节点/轮次/门禁/依赖，Python 解析 + TS 编排插件
4. **运行度量（D6）**：run_event JSONL 事件库 + 历史静态解析，看板聚合展示
5. **DSH 适配**：cordis profile（bundles + patch 层）+ 3 个 TS 插件薄适配 + agents/skills 迁移；
   拓扑契约（.harness-env）不变

## 四、测试结果

- 全量 **106** 用例通过（86 新增 + 20 既有拓扑；`unit_test/test/test_harness_dsh_result.txt`）
