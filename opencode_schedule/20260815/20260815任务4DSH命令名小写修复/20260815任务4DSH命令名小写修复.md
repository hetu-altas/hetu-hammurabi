## 一、任务要求

### 需求背景
用户运行 `npm exec @deepseek-ai/dsh web` 报错：

```
command name "CC" must match /^[a-z][a-z0-9_-]*$/u
```

DSH 命令名必须**小写开头**（正则 `/^[a-z][a-z0-9_-]*$/u`），而 `harness/dsh/plugins/charter-command.ts` 将命令名写成了大写 `"CC"`，导致 charter-command 插件加载失败、DSH web 无法启动。

根因：20260815 任务3（/dev 更名 /cc）把 DSH 侧命令插件 `harness/dsh/plugins/charter-command.ts` 的命令名写成了大写 `"CC"`（L24 `const name = "CC";`、L133 `name: "CC",`），违反 DSH 命令名校验；L2/L4/L14/L75/L150/L166 注释与提示文案同步为 `/CC`。本任务将其统一改为小写 `cc`（cc = constitution coding，语义不变：`/cc <任务书路径 或 一句话需求>`）。

## 四、接口 / 数据格式定义

- **DSH 命令名校验正则**（@deepseek-ai/dsh-commands）：`/^[a-z][a-z0-9_-]*$/u`（小写字母开头，可含小写字母/数字/下划线/连字符）
- **命令名**：`cc`（cc = constitution coding，宪章编程；语义与 20260815 任务3 的 opencode 入口 `.opencode/commands/cc.md` 一致，双体系同名）
- **输入**：`/cc <任务书路径 或 一句话需求>`（三模式：任务书路径 → 读任务书；非空文本 → 一句话需求；空 → 提示用法）
- **输出**：`kind: "success"` + 流程启动确认文本（含 `/cc` 文案）；`kind: "error"` + 提示文本（含 `/cc <任务书路径 或 一句话需求>` 用法）
- **关键字段**：`name`（命令名，插件导出 `export { name, inject, apply }`）、`description`（宪章编程（constitution coding）说明，不含 CC 大写）、`inject`（`["commands"]`）、`handler`（注入 user message 唤醒模型）
