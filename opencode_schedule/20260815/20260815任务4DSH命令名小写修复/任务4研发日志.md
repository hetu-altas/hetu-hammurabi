## 一、任务概述

修复 DSH 命令插件命令名大写残留问题：用户运行 `npm exec @deepseek-ai/dsh web` 报错 `command name "CC" must match /^[a-z][a-z0-9_-]*$/u`，导致 charter-command 插件加载失败、DSH web 无法启动。

完成以下修复：

1. **命令名小写化**（核心产出）：`harness/dsh/plugins/charter-command.ts` 8 处 `"CC"`/`/CC` → `"cc"`/`/cc`（命令名 + 文案），通过 DSH 校验正则，恢复 `npm exec @deepseek-ai/dsh web` 启动；
2. **测试同步**：`command.test.mjs` 3 处断言/标题更新（`cmd.name === "cc"`、`/cc` 文本断言），node 单测 6/6；

4. **回归补强**：`unit_test/test_cc_command.py` 新增 2 用例（共 10），固化「DSH 插件命令名小写 + 命令引用零残留」检测，补齐任务3 评审遗留「检测模式形态扩展」项；
