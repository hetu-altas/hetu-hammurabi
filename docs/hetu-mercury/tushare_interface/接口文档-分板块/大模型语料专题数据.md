## major_news
新闻通讯（长篇）

描述: 获取长篇通讯信息，覆盖主要新闻资讯网站，提供超过8年历史新闻。
限量: 单次最大400行记录，可循环提取保存到本地。

### 输入参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| src | str | 新闻来源（新华网、凤凰财经、同花顺、新浪财经、华尔街见闻、中证网、财新网、第一财经、财联社） |
| start_date | str | 新闻发布开始时间，e.g. 2018-11-21 00:00:00 |
| end_date | str | 新闻发布结束时间，e.g. 2018-11-22 00:00:00 |

### 输出参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| title | str | 标题 |
| content | str | 内容 (默认不显示，需要在fields里指定) |
| pub_time | str | 发布时间 |
| src | str | 来源网站 |
