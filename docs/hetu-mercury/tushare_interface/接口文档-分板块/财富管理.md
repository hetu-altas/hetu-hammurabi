## fund_sales_ratio1002015
各渠道公募基金销售保有规模占比

### 输入参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| 年份 | str | 年度 |

### 输出参数

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| year | int | 年度 |
| bank | float | 商业银行（%） |
| sec_comp | float | 证券公司（%） |
| fund_comp | float | 基金公司直销（%） |
| indep_comp | float | 独立基金销售机构（%） |
| rests | float | 其他（%） |
