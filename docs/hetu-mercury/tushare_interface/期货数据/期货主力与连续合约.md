# 期货主力与连续合约

## 接口名
fut_mapping
## 描述
获取期货主力（或连续）合约与月合约映射数据
## 限量
单次最大2000条，总量不限制
### 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | 合约代码 |
| trade_date | str | N | 交易日期(YYYYMMDD格式，下同) |
| start_date | str | N | 开始日期 |
| end_date | str | N | 结束日期 |

### 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 连续合约代码 |
| trade_date | str | Y | 起始日期 |
| mapping_ts_code | str | Y | 期货合约代码 |
