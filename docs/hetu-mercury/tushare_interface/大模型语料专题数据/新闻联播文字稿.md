# 新闻联播文字稿

## 接口名
cctv_news

## 描述
获取新闻联播文字稿数据，数据开始于2017年。

## 限量
可根据日期参数循环提取，总量不限制

### 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| date | str | Y | 日期（输入格式：YYYYMMDD 比如：20181211） |

### 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| date | str | Y | 日期 |
| title | str | Y | 标题 |
| content | str | Y | 内容 |

## 接口示例
```python
pro = ts.pro_api()

#获取2018年12月11日新闻联播文字稿内容
df = pro.cctv_news(date='20181211')
```
