# 指数实时日线

## 接口名
rt_idx_k
## 描述
获取交易所指数实时日线行情，支持按代码或代码通配符一次性提取全部交易所指数实时日k线行情
| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 指数代码，支持通配符方式，e.g. 0*.SH、3*.SZ、000001.SH |

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 指数代码 |
| name | str | Y | 指数名称 |
| trade_time | str | Y | 交易时间 |
| close | float | Y | 现价 |
| pre_close | float | Y | 昨收 |
| high | float | Y | 最高价 |
| open | float | Y | 开盘价 |
| low | float | Y | 最低价 |
| vol | float | Y | 成交量 |
| amount | float | Y | 成交金额（元） |
