# 管理层薪酬和持股

## 接口名
stk_rewards
## 描述
获取上市公司管理层薪酬和持股
### 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | TS股票代码，支持单个或多个代码输入 |
| end_date | str | N | 报告期 |

### 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | TS股票代码 |
| ann_date | str | Y | 公告日期 |
| end_date | str | Y | 截止日期 |
| name | str | Y | 姓名 |
| title | str | Y | 职务 |
| reward | float | Y | 报酬 |
| hold_vol | float | Y | 持股数 |
