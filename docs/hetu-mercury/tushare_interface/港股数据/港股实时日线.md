# 港股实时日线

## 接口名
rt_hk_k
## 描述
获取港股实时日k线行情，支持按股票代码及股票代码通配符一次性提取全部股票实时日k线行情
## 限量
单次最大可提取5000条数据
### 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 支持通配符方式，e.g. 00001.HK、02*.HK |

### 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | Y | 股票代码 |
| pre_close | float | Y | 昨收价 |
| close | float | Y | 收盘价 |
| high | float | Y | 最高价 |
| open | float | Y | 开盘价 |
| low | float | Y | 最低价 |
| vol | float | Y | 成交量（股） |
| amount | float | Y | 成交额(元) |
