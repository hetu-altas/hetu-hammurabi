# 国债长期利率

## 接口名
us_tltr描述：国债长期利率限量：单次最大可获取2000行数据，可循环获取权限：用户积累120积分可以使用，积分越高频次越高。具体请参阅积分获取办法

### 输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| date | str | N | 日期 |
| start_date | str | N | 开始日期 |
| end_date | str | N | 结束日期 |
| fields | str | N | 指定字段 |

### 输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| date | str | Y | 日期 |
| ltc | float | Y | 收益率 LT COMPOSITE (>10 Yrs) |
| cmt | float | Y | 20年期CMT利率(TREASURY 20-Yr CMT) |
| e_factor | float | Y | 外推因子EXTRAPOLATION FACTOR |
