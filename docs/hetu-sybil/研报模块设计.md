## 四、研报数据视图定义（零信号）

```json
{
  "ts_code": "...", "source": "stock_report", "trade_date": "...",
  "research_view": {
    "meta": {"total_recalled": N, "candidates": M},
    "by_institution": [{"institution": "...", "count": n, "latest_date": "...",
                        "reports": [{"publish_date", "title", "section", "content_excerpt", "report_type"}]}],
    "stats": {"institution_count", "report_count_total",
              "rating_keywords": {"买入": n, ...}, "price_target": {"max"/"min"/"median"/"count"}}
  },
  "data_freshness": {"latest_report_date", "lag_days"},
  "coverage": {"overall": "ok|stale|missing", "missing_reasons": [...]}
}
```

- 基础统计特征=数据加工：机构覆盖数/研报数/**评级关键词词频**（频次≠倾向）/目标价数值正则提取（数值≠空间判断）；
- 0 命中视图可产出（stats 空 + coverage=missing + 原因）。

## 五、就绪校验

| 状态 | 判定 | AI 侧处置 |
|------|------|----------|
| ok | 命中>0 且最新研报 ≤90 天 | 正常研判 |
| stale | 命中>0 但 >90 天 | 声明知识时点、降 confidence |
| missing | 0 命中 | 声明缺失原因、弃用或 neutral |

## 六、AI 研判流程与分节要点

- 运行期链路（任务 11）：研报分析流水线 → `analyze_research` 输出视图 → 变量填充 `src/prompts/research-analysis.md` → AI 研判 → research 信号 JSON（signal_type 初版枚举：research_sentiment/rating/price_target/attention/composite）→ validate_signal → 记录；
- 研判四维（非规则公式）：观点一致性/评级倾向/目标价空间/关注度变化；
- 交付物：`src/prompts/research-analysis.md` + `docs/skills/sybil-analysis-flow/研报分析分节.md`（与代码同源）。
