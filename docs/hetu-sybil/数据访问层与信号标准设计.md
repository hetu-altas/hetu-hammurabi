## 1. 信号 JSON 标准（架构 4.2.3 落地）

### 1.1 11 字段 schema

```json
{
  "signal_id": "sig_20260808_fund_000001_SZ_001",
  "module": "fundamental",
  "ts_code": "000001.SZ",
  "trade_date": "2026-08-08",
  "signal_type": "financial_health",
  "direction": "bull",
  "score": 72.5,
  "confidence": 0.81,
  "summary": "ROE 与毛利率连续两季改善，现金流覆盖良好，预期差为正",
  "evidence": [
    {"table": "fina_indicator", "period": "2026Q1", "metric": "roe", "value": 11.2},
    {"source": "report_rc", "org_name": "华泰证券", "rating": "买入", "eps_pred": 1.25}
  ],
  "meta": {"data_freshness": "2026-08-07", "data_coverage": "ok"}

```

### 1.2 常量对照表（`src/signal/signal_schema.py`）

| 常量 | 值 | 说明 |
|------|-----|------|
| `SIGNAL_REQUIRED_FIELDS` | 11 字段（signal_id/module/ts_code/trade_date/signal_type/direction/score/confidence/summary/evidence/meta） | 必填字段清单，顺序与架构 4.2.3 示例一致 |
| `SIGNAL_MODULES` | fundamental/macro/research/news/technical/capital/rating/**market**/review（9 枚举，T8-2 演进 +market） | technical 与 capital 同属个股数据分析模块 3.5；market 为大盘模块 3.6.1；review 为复盘枚举 |

| `SIGNAL_DIRECTIONS` | bull/bear/neutral（3 值） | — |
| `SCORE_MIN` / `SCORE_MAX` | 0 / 100 | 待确认A：默认不支持负值表达偏空 |
| `CONFIDENCE_MIN` / `CONFIDENCE_MAX` | 0.0 / 1.0 | — |
| `TRADE_DATE_FORMAT` | `"%Y-%m-%d"` | trade_date / meta.data_freshness 日期格式 |

### 1.3 校验规则（`src/signal/signal_validator.py::validate_signal`，9 条，不短路）

| # | 规则 | 失败示例 |
|---|------|---------|
| ① | 必填 11 字段完整（缺失项按清单顺序输出） | 缺 `evidence` |
| ② | `module` ∈ SIGNAL_MODULES | `module="quant"` |
| ③ | `direction` ∈ SIGNAL_DIRECTIONS | `direction="sideways"` |
| ④ | `score` 为数值（bool 除外）且 ∈ [0,100] | `score=101` / `score="high"` |
| ⑤ | `confidence` 为数值且 ∈ [0,1] | `confidence=1.5` |
| ⑥ | `trade_date` 符合 `%Y-%m-%d` 可解析 | `trade_date="2026/08/08"` |
| ⑦ | `evidence` 为 list（允许空） | `evidence={"table": ...}` |
| ⑧ | `meta` 为 dict 且含 `data_freshness`（日期字符串） | meta 缺 data_freshness |
| ⑨ | `ts_code`/`signal_id`/`signal_type` 为非空字符串 | `ts_code="  "` |

- 返回 `(bool, list[str])`（函数类型标注：`-> Tuple[bool, List[str]]`），错误信息中文，通过时列表为空；**额外字段容错**（非清单键不报错）。
- review 口径：`review` ∈ SIGNAL_MODULES 但不 ∈ SIGNAL_TRADE_MODULES（不参与六大交易信号聚合，仅归档）。

```python
# src/data_access/tdengine_access.py —— TDengine 只读封装（get_tdengine 单例 + with 上下文）
def query(super_table: str, ts_code: str, start_date: str, end_date: str,

# src/data_access/milvus_access.py —— Milvus recall 封装（复用 util_milvus）
def recall(vectors: list, top_k: int = 10, metadata_filter: Optional[str] = None,
```

**批量查询模板（契约演进，20260812 任务 3 补充 1 新增，向后兼容）**：

```python
from src.data_access import query_batch

# 批量拉取多只标的（列表即批；分批职责在调用方，默认批大小 BATCH_SIZE=400）
```

- 批量 SQL 模板：`SELECT {fields} FROM {super_table} WHERE ts_code IN ('c1', 'c2', ...) AND ts >= '{start_date} 00:00:00' AND ts < '{end_exclusive} 00:00:00'`（end_exclusive=end_date 次日，半开区间同 query）；
- 红线继承：ts_codes **逐项白名单校验**（任一非法整体拒绝 ValueError，禁止部分放行）、
  None/空列表/缺 start_date/end_date → ValueError（禁止全表扫描强制）、表名/字段/日期白名单
  校验复用 `_validate_super_table`/`_validate_ts_code`（逐项）/`_validate_date`/`_validate_fields`、
  `with get_connection()` 执行 + 异常包装 RuntimeError（同 query）；
- **分批约定**：`query_batch` 自身按调用方传入列表一次执行（列表即批），批大小切分由调用方
  负责（`src/analysis/stock_analysis/stock_config.py::BATCH_SIZE=400`，待确认T8 默认值，
  每批 300~500 只区间）——保持接口纯粹，避免嵌套循环；
- GreatSQL 侧评估结论（设计决策）：`query_all` 已支持参数化多条查询，**不新增** IN 子句封装
  （股东/质押/回购等慢变量表单标的查询场景为主，批量 IN 场景有限且参数化 %s 已满足；
  如需扩展如按报告期批量取 top10_holders，留待后续任务评估）。

- **防注入（最高优先级）**：taosrest REST API 不支持参数化（util_db.py L349/L359 注释明示），SQL 由本模块构造，入 SQL 的值全部先经白名单正则/格式强校验：
  - `super_table`：`^[a-z_][a-z0-9_]*$`；`fields` 逐项同白名单；日期：`datetime.strptime(..., "%Y-%m-%d")`；
  - **ts_code（S4 评审修复，点分结构 + 后缀枚举，拒绝畸形代码）**：`^(?:\d{5,6}\.(?:SH|SZ|BJ|HK)|[A-Z]{1,6}\.US|[A-Z]{1,4}\d{0,4}\.(?:SHF|CFX|CZC|DCE|INE|GFEX|CF|IF|IO))$`——覆盖 A 股/指数/ETF/转债（`000001.SZ`、`000300.SH`、`830799.BJ`）、港股（`00700.HK`）、美股（`AAPL.US`）、期货（`RB2510.SHF`、`IF1707.IF`）；无后缀、超长、后缀非法、点号堆叠等畸形代码拒绝；
  - **ts_code/start_date/end_date 缺一即抛 ValueError（禁止全表扫描强制）**；
- SQL 模板（半开区间防跨日重复）：

  ```sql
  SELECT {fields} FROM {super_table}
  WHERE ts_code = '{ts_code}' AND ts >= '{start_date} 00:00:00' AND ts < '{end_exclusive} 00:00:00'
  ```

  其中 `end_exclusive = end_date 次日`；fields=None/[] 时 `SELECT *`；
- 执行：`with get_tdengine(...).get_connection() as conn: conn.query(sql)`（结果 `result.data`，util_db L355-364）；
- 超级表模型统一：时间列 `ts` + 标签列 `ts_code`（mercury DDL：股票数据.sql daily L503、weekly L542、monthly L740；宏观经济.sql 18 超级表 L16~L418）；
- 连接失败异常包装 RuntimeError 透传，由任务 3~8 调用方决定信号降级（架构 4.4 门禁口径）。
