# hetu-sybil 新闻模块设计

> **任务**：20260815任务7「新闻分析模块」（编码任务，M2）｜ **日期**：2026-08-15

## 一、模块职责与零规则信号边界

- **代码职责**：双源取数（Milvus 新闻四源无标的召回 + GreatSQL eco_cal 财经事件 + 热榜 dc_hot/ths_hot）→ 双源数据视图（数据加工非信号）→ 就绪校验 → CLI；
- **信号产出归 AI**：news 信号（情绪倾向/宏观环境/事件驱动/综合）由 AI 按 `src/prompts/news-analysis.md` 研判；
- **零规则信号断言**：`test_no_rule_signal_news.py`（源码级扫描 + 输出结构断言 + 伪模块自检）。

## 二、召回设计（契约级，任务书"二"节）

| 场景 | 源 | 召回方式 | 说明 |
|------|-----|---------|------|
| 宏观/市场级 | Milvus news/major_news/cctv_news/npr | 时间窗标量过滤 + 向量语义召回（宏观主题查询） | 无标的（stock_code=None 实测） |
| 个股相关 | 同上 | 语义召回（query 含标的）+ 视图层 keyword_hit 标注 | 关键词过滤为数据组织非研判 |
| 国内外财经事件 | GreatSQL eco_cal | 时间窗参数化查询（date 索引，= 匹配规避 LIKE 通配符冲突） | value/pre_value/fore_value 透传，预期差判断归 AI |
| 关键事件 | major_news + eco_cal | 事件视图数据特征 + AI 关键性判断 | 央行决议/CPI/PPI/地缘等 |
| 热榜热度 | dc_hot/ths_hot | 时间窗热度数据组织（rank/pct_change/hot/rank_reason） | 按表字段差异适配 |

**契约演进 T7-1**：`build_recall_kwargs` 支持 `ts_code=None`（metadata_filter 仅 source+时间窗）；源白名单 8→9 源（+cctv_news）；向后兼容（非 None 行为不变）。

## 三、双源视图设计

| 源 | 内容 | 缺失处理 |
|----|------|---------|
| news_view | Milvus 四源分源组织（publish_datetime/content/age_band，个股模式含 keyword_hit） | 0 命中 → missing |
| eco_cal_view | 财经事件（date/country/event/value/pre_value/fore_value）latest/series/meta | 表缺失 → missing 标注 |
| hot_view | 热榜（dc_hot 基础列/A股市场、ths_hot 扩展列/热股） | 异常 → 该表空组织 |

- 时效分档：fresh≤7 天 / recent≤30 天 / stale>30 天（meta.age_bands，trade_date 基准）；
- eco_cal 数据滞后（实测最新 2026-05-31）→ meta.note + data_freshness 如实标注，AI 降权声明。

## 四、实测发现（2026-08-15）

1. **news 无 stock_code**：个股模式按 stock_code 过滤 0 命中 → 一律无标的召回 + keyword_hit 标注；
2. **MySQL RANK 保留字**：热榜 ORDER BY rank 报 1064 → 反引号包裹（SELECT/ORDER BY 均处理）；
3. **DECIMAL 序列化**：热榜数值 → float 转换；
4. **dc_hot/ths_hot 差异**：dc_hot 无 hot/rank_reason/concept 且 data_type='A股市场'（ths_hot='热股'）→ 按表适配；
5. **LIKE 与参数化冲突**（`LIKE '%中国%'` 实测 not enough arguments）→ 事件/热榜过滤用 = 匹配。
