## 一、模块职责与零规则信号边界

- **代码职责**：TDengine 只读取数（index_daily/index_global_daily/fut_daily）→ 指数/商品双视图组织（区间涨跌幅/MA5/MA20 等**基础统计特征**，数据加工非信号）→ 按天/区间双模式 → 就绪校验 → CLI；
- **信号产出归 AI**：market 信号（大盘趋势/市场情绪/跨市场与商品联动/综合）由 AI 按 `src/prompts/market-analysis.md` 研判；
- **零规则信号断言**：`test_no_rule_signal_market.py`（源码扫描 + 输出结构断言 + 伪模块自检）。

## 三、双视图与模式

- `index_view`：latest/series + stats（区间涨跌幅/MA5/MA20/high/low/avg）+ freshness（fresh≤3/recent≤10/stale>30）；
- `commodity_view`：主力合约 latest/series + stats + freshness；
- 按天 `--days N`（时间窗）/区间 `--start/--end`（优先）双模式；
- coverage/data_freshness/missing_tables 与任务3~7 同构；国际指数各市场时差以标的各自最新日呈现（meta 标注）。
